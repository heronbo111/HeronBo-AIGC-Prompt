Agent 用豆包工作版的文本模型做规划，只负责建节点；生成要手动点「开始生成」，避免偷偷消耗额度。

所有画布与素材都保存在本机 data\ 目录，不会上传任何云端。

一个节点的上游连线里，只有第一张图片会作为参考图发给豆包（网关单图限制）；上游文本节点会拼进提示词。

视频生成较慢（1~5 分钟），可以同时排多个节点的任务。
