## 改脚本时的硬约定

1. **口径不写死在脚本里**：凡是"agent 该怎么做"的规则落 `references/rules.md`，脚本里的指令文案
   **引用条号**（例：「按 rules 第 66 条」）。写死在源码里的口径，换机器就没人读得到。
2. **改"按类型查表"的文案必须同时补表**：`workbench_server.py` 的 `STAGE_NAMES` 之类，
   表里缺一项会**静默**退回默认文案（用户看得见，报错看不见）。
3. **交互期文案只面向用户**：界面/日志里不出现进程名、PID、命令行原文；原始细节收在「执行记录」可展开区。
4. **`.cmd` 批处理必须纯 ASCII + CRLF**（中文一律交给 Python 打印）——cmd.exe 按当前代码页逐字节解析，UTF-8 中文会被切碎。
5. **临时脚本别留在 `tools/`**：调试用完就删；`_vendor/`、`dist/`、`_stage/` 都是生成物，只搜不读。
6. **`project_core.py` 是项目骨架的唯一入口**：回执/待办/清单/@编号都走它；
   出提示词那一轮用 `--assemble` 拼 `提示词.txt`（正文只写一遍），**多版本项目它会被拒**（要自己写）。
7. **注释口径统一用中文**：产品/界面统一称「创作台」；只有 `_工作台反馈`、`工作台日志.jsonl` 这类历史文件名保留「工作台」。英文界面只换界面文案，不翻代码注释。

## 客户端文案只讲人话（写死，不许商量；2026-11-17 用户裁定）

> 用户原话（工作台开发对话）："所有信息返回不要带那么详细的描述，比如通道通了就说**通道已接通可以继续使用了**（不必带 9333 端口这种详细的话）；通道没连上要提醒用户去点**联通测试**；没找到 Agent 就直接说**没找到可用 Agent，建议下载豆包工作**。"
> 结论：**客户端开发里，凡是用户看得见的字，一律不许出现专业性描述，只用他能懂的简易白话。**

**管辖范围**——用户看得见的每一个字：界面状态条、弹窗标题与正文、按钮名、报错、更新与安装提示、
托盘气泡、首次配置页、Agent 卡住时的提示语。
**不管辖**——源码注释、`_会话/工作台日志.jsonl`、`_会话/agent记录/*.jsonl`、崩溃日志：
细节要留，但只能留在这些地方，不许漏到界面上。

**四句口诀**：先说现在什么情况 → 再说该点哪里 → 一句就够 → 剩下的收进「执行记录 / 详情」。

**硬规矩**

1. **不许出现的东西**：端口号与地址（`9333`、`127.0.0.1:47xxx`）、进程名与 PID、命令行原文、
   内部文件名与路径、技术名词（CDP、CLI 通道、IPC、preload、WebSocket、JSON、API、SDK、token、
   traceback、`HTTP 4xx/5xx` 英文原文）。
2. **状态句只写"结果 + 动作"**：`通道已接通，可以继续用了` ／ `没连上，请点【联通测试】再试一次` ／
   `没找到可用的 Agent，建议先下载豆包工作`。按钮名必须和界面上显示的一字不差，用户才找得到。
3. **一个毛病只给一个说法**：不要罗列七八条可能原因让用户自己对号；先说最可能的那条 + 一个动作，
   实在排查不了再说"把这条记下来给开发"。
4. **原始细节不删，只挪位置**：默认折叠进「执行记录 / 详情」；用户点开能看见，收起时看不见。
5. **不许用"错误 / 失败 / 异常"打头吓人**：自己能好的就说"正在自动重试，稍等一下"；
   真要用户动手才说"打不开，请点【X】"。
6. **英文界面只换界面文案**，不翻代码注释；中文界面也不许为了"专业感"把技术词留着。

**对照表（改文案时照着换）**

| 别这么写（现在常犯的） | 这么写（用户看得懂） |
|---|---|
| `CDP 通道 9333 已连接` | `通道已接通，可以继续用了` |
| `CDP / CLI 切换失败（exit 1）` | `连接方式没切换成功，请点【联通测试】再试一次` |
| `未检测到 Agent 进程，pid=17864` | `没找到可用的 Agent，建议先下载豆包工作` |
| `HTTP 500 / 请求失败` | `这次没连上，请点【重试】` |
| `token 失效（401）` | `登录状态过期了，请重新登录` |
| `IndexedDB / localStorage 写入失败` | `本机记录没存上，请再试一次` |
| `转码失败：H.264 不支持` | `这段视频太大，正在自动处理，稍等一会儿` |
| `拉取更新包失败（sha256 不匹配）` | `新版本没下完，请再点一次【检查更新】` |
| `pyinstaller 打包产物缺失` | 用户不该看到这句——写进日志 |
| `端口 9333 被占用，启动失败` | `工作台打不开，请先关掉已经开着的窗口再试` |
