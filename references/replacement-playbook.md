# 替换类作战手册（人物/物件替换进既有画面）

> 2026-09-09 调研整理（含实测证据 + 平台调研）。规则正文见 rules.md 第20/20b/21/22/23/24 条；本文件是 L1–L4 分级的工具与流水线细节。调研方法：平台官方页 + agent 检索（2026-09-09），价格与功能以产品页为准。

## 一、难易度分级（基于本系列实测）

| 级别 | 任务 | 本系列实例 | 结论 |
|---|---|---|---|
| **L1 物件替换** | 商品/道具替换，无人物属性（拟人化） | 考研真题拟人化替换果冻原片 | ✅ C1 拟人化配方 2/2 成功（视频锚定+商品图替换唯一主角+Q弹+原声+背景色迁移） |
| **L2 台词替换** | 人物/场景全保留，只换口播内容 | 样本4（两本书）、样本6（背单词） | ✅ 参考视频+音色参考+台词引号，"完美/很不错" |
| **L3 同人造型替换** | 同一真人换装/换手中物件 | 三本书（黑上衣+三本新封面） | ⚠️ 两步法（规则23）：图片层 image2image 做替换 → 视频层零替换；视频层直接替换不可靠 |
| **L4 人物替换进原片** | 换人 + 复刻原片动作/镜头/场景 | 示例-直播空降（复刻"神临"）、示例-影视替换（影视） | ❌ 通用视频模型不可行（锚定压制替换/身份漂移/节奏不卡）→ 必须用专用动作迁移工具（见下） |

**核心原则（规则23）**：内容替换交给图片模型，视频模型只做"动起来"；L4 用专用动作迁移模型，不用通用视频生成硬顶。

## 二、L4 推荐路线（2026-09 调研）

### 首选：Wan-Animate-2 Mix（阿里开源，2026-08-07 发布）
- 唯一生产级的"换人保场景"：角色图 + 驱动视频 → 替换原片人物，**保留原片场景、动作、打光**（Relighting LoRA）
- v2 改进：去掉骨架提取器、直接吃驱动视频、手部/表情伪影减少、盲测 >70% 偏好优于 v1；Viewpoint LoRA（12方位×4仰角）、跨体型动作重定向
- 无口型 → 后接对口型步骤
- 获取：开源权重 https://github.com/Wan-Video/Wan-Animate-2 ；ModelScope demo；托管 https://wan-animate.com/zh（2–30s，<200MB，480p 1积分/s、720p 4积分/s，登录免费）
- 硬件：14B，本地需大显存；ComfyUI/DiffSynth 可自部署；实时流需多卡
- 输入要求：主体居中清晰、画幅匹配、建议先跑 2–10s 短测

### 备选
- **可灵 动作控制3.0**（GA）：1角色图+1参考视频 → 骨架+镜头逻辑+表情迁移（30s 武打级动作、230+面部关键点）；注意**场景重绘、不保原片背景**。后接 数字人2.0 Pro（换装/场景切换/对口型，最长5分钟）或 2.6 原生音画同出
- **Vidu API 全家桶**（自动化最友好）：motion-sync（角色图+驱动视频3–30s，单人正面、脸无遮挡）+ lip-sync（视频+音频/TTS，1–600s）+ 一键复刻（源视频5–180s+1–7张商品/模特图）+ reference2video（viduq2-pro 明确支持"参考视频/视频编辑/视频替换"）；API 文档 https://platform.vidu.cn/docs
- **腾讯 HunyuanCustom**（开源研究）：视频驱动模式下"用带身份信息的参考图替换源视频中指定对象，源视频提供动作与环境"——与 Wan-Animate-2 同类，无产品化 UI
- **海外基准**：Runway Aleph（视频内改主体）+ Act-Two（表演迁移）、Viggle（角色替换进既有视频）——效果标杆，国内访问/合规自行评估

### 口型/音色补齐（L4 后期）
- 口型：Vidu lip-sync（API）、可灵 `/v1/videos/lip-sync`、即梦"数字人/对口型"；注意即梦对口型 5–8s 后相似度会降（社区反馈），长片分段
- 音色：参考音频7（已有）或声音克隆（Vidu voice clone、CosyVoice/GPT-SoVITS）
- 换装精修（如需）：即梦 AI clothes changer、IDM-VTON/CatVTON
- 换脸精修（如需）：InstantID/PuLID/ReActor/FaceFusion 关键帧精修后回贴

## 三、通用失败模式（迁移类通病）
1. 遮挡与手部交互（手持物、自遮挡、侧脸）是最大失败点
2. 身份漂移：长片 5–8s 后相似度下降 → 控制在 5–10s 或分段+身份锁定
3. 打光/色调不一致 → 选带 Relighting 的方案（Wan-Animate-2）
4. 相机/背景保留大多数产品不承诺（Kling/即梦会重绘场景）
5. 输入限制：单人正面、脸无遮挡、2–30s、<200MB、720p 档 25fps
6. 厂商指标（>95% 微表情保真等）是营销口径，未见独立评测

## 四、合规
- 替换真人脸/声音需本人书面授权；深度合成内容需标注 AI 生成（生成式AI/深度合成管理规定）
- 影视片段替换（示例-影视替换类）过审难、审核规避处理代价大（规则第7条）——**优先自拍原片做驱动视频**
