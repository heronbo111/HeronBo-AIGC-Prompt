# 替换类作战手册（人物/物件替换进既有画面）

> 2026-09-09 调研整理（含实测证据 + 平台调研）。规则正文见 rules.md 第20/20b/21/22/23/24 条；本文件是 L1–L4 分级的工具与流水线细节。调研方法：平台官方页 + agent 检索（2026-09-09），价格与功能以产品页为准。

## 一、难易度分级（基于本系列实测）

| 级别 | 任务 | 本系列实例 | 结论 |
|---|---|---|---|
| **L1 物件替换** | 商品/道具替换，无人物属性（拟人化） | 考研真题拟人化替换果冻原片 | ✅ C1 拟人化配方 2/2 成功（视频锚定+商品图替换唯一主角+Q弹+原声+背景色迁移） |
| **L2 台词替换** | 人物/场景全保留，只换口播内容 | 样本4（两本书）、样本6（背单词） | ✅ 参考视频+音色参考+台词引号，"完美/很不错" |
| **L3 同人造型替换** | 同一真人换装/换手中物件 | 三本书（黑上衣+三本新封面） | ⚠️ 两步法（规则23）：图片层 image2image 做替换 → 视频层零替换；视频层直接替换不可靠 |
| **L4 人物替换进原片** | 换人 + 复刻原片动作/镜头/场景 | 示例-直播空降（复刻"神临"）、示例-影视替换（影视） | ❌ 通用视频模型不可行（锚定压制替换/身份漂移/节奏不卡）→ 必须用专用动作迁移工具（见下） |

**核心原则（规则23）**：内容替换交给图片模型，视频模型只做"动起来"；L4 用专用动作迁移模型，不用通用视频生成硬顶。

## 二、L4 推荐路线（2026-09 调研；2026-09-11 按用户付费能力调整）

### 首选（本系列）：即梦平台内 —— 把驱动视频转成「深度视频」做信息过滤，再让 Seedance 换人（零额外付费）

> **选型理由**：用户目前**只有即梦会员**，外部工具（Wan-Animate-2 托管要按量付费、自部署要 14B 大显存；可灵/Vidu/Runway 同理）**暂不采用**。这条是**在即梦内就能做**的路线（2026-09-11 用户指令）。

- **针对问题**：规则20b「参考视频锚定会压制替换指令」——原片自带脸、服装、背景、灯光与整体风格，模型会一起照抄，替换句失效（三本书 B 版实证）。
- **做法**：把驱动视频**转成黑白深度视频**（只保留人物动作姿态与前后空间关系），**按 15 秒以内切分**，当 @视频1 用；再配 **人物图（只管角色）＋ 场景图（只管环境）**。
- **提示词写法**（逐项锁定 ＋ 反向排除，缺一不可）：

  ```
  @视频1 只参考动作、动作顺序、节奏、身体幅度和姿态变化，
  不要参考它的黑白画面、人物身份和原始场景；
  人物严格参考@图1（面部、发型、服装）；环境严格参考@图2。
  ```

- **适用**：舞蹈、走秀、武术、人物表演等"对动作节奏要求高"的复刻；也适合"复刻动作但换人换环境"。
- **画幅（rules 第26条）**：替换类默认**交付 9:16 竖版**；横版驱动视频先用 `python tools\竖版画布.py -i "<横版原片>"`（默认 crop 满屏竖版、只裁左右且人脸自动定位；`--mode pad` 走不裁切的竖版画布）转成竖版再进去。即梦「智能编辑 / 全能参考」的画幅跟随提交设置，**提交时手选 9:16**。
- **依据**：第三方教程《Seedance新玩法》（原文与两段示例提示词见 `${SAMPLES_ROOT}\_范本调研_2026-09-11\第三方教程_Seedance深度视频换人法.md`）＋ rules 第30条。博主只展示效果，本机未实测，故标待验证。

- **更好的中间态：人物遮罩片**（2026-09-11 新增）——用 `tools\人物遮罩.py` 把**人物区域糊掉、场景保持清晰**（实测 `--check` 7/7 时间点 0 人脸，场景区清晰度 82.8、人物区 14.6）。
  深度片把场景/光线/机位一起丢了，原片又把身份锁死；**遮罩片只去掉"人物长什么样"**，是这条路线目前最均衡的输入 —— 配"目标图"当 @图片1 用（提示词写法见样本库 `中国人能飞替换\文案\提示词_模糊片路线_v1.txt`）。

✅ **前置能力（2026-09-11 已建）**：本机已具备"转黑白深度视频"能力——`tools\深度视频.py` + Depth-Anything-V2-Small ONNX（模型放本机缓存，不进仓库），实测 1.97 帧/秒。安装与用法见 `references/depth-video-setup.md`。**顺序：先 `竖版画布.py` 转竖版，再转深度。**

### 已建工具：深度视频转换（`tools\深度视频.py`，2026-09-11 建并实测）

输入一段横版/竖版参考视频 → 输出**黑白深度视频**（只留动作姿态与前后空间关系，近处亮），可按 15 秒以内自动分段。

```bash
python tools\深度视频.py --check "<参考视频>"            # 看参数 + 模型是否就位
python tools\深度视频.py -i "<参考视频>" --segment 15      # 转深度并按 15 秒分段
python tools\深度视频.py -i "<参考视频>" --max-frames 30   # 短测
```

- **顺序**：先把源片转竖版（`tools\竖版画布.py`），**再**转深度。
- **模型**：Depth-Anything-V2-Small（ONNX fp32，99MB）放在 `~/.cache/depth-models/`，**不进仓库**；换机重建见 `references/depth-video-setup.md` 第二节。
- **实测性能**：CPU **1.97 帧/秒**；14s / 30fps（420 帧）约 3.5–4 分钟。
- **验收（无视觉）**：规格与源片一致且无音轨｜R≈G≈B 是灰度｜**人物中心带比背景亮**（实测 152.1 vs 5.2）｜抽帧 OCR 无文字。
- **备选（不推荐）**：直接让即梦生成"黑白深度风格"视频——那是风格化灰度，**不是真深度**（真深度是逐像素远近），还要花积分排队。

## 三、通用失败模式（迁移类通病）
1. 遮挡与手部交互（手持物、自遮挡、侧脸）是最大失败点
2. 身份漂移：长片 5–8s 后相似度下降 → 控制在 5–10s 或分段+身份锁定
3. 打光/色调不一致 → 选带 Relighting 的方案（Wan-Animate-2）
4. 相机/背景保留大多数产品不承诺（Kling/即梦会重绘场景）
5. 输入限制：单人正面、脸无遮挡、2–30s、<200MB、720p 档 25fps
6. 厂商指标（>95% 微表情保真等）是营销口径，未见独立评测
7. **横版源片直接要竖版输出 = 模型替你重构图**（人物放大 2–3 倍、构图改变）：先把源片转竖版输入再要求"不裁切不放大"（rules 第26条 + `tools\竖版画布.py`），不可依赖提示词让模型保留横版构图

## 四之二、MV / 音乐二创类换人替换（2026-09-12 新增：两组拆解实测 + 第三方作者配方；本机未端到端跑通，待验证）

**形态**：一条 MV / 音乐短片，保留歌、编舞、场景、机位与**剪辑点**，只把人物层换成目标角色（rules 第36条）。两组实测均证实这是当前爆款二创的主流做法：
- `参考1–4`（真人歌舞片 → 红白模/女版/希特勒三版）：剪辑点与原片 7.73/11.5/14.9s 三处重合 ±0.5s；
- `《琵琶曲》系列`（3D 动画 → 动漫/meme/生化/战术四版）：25–35 个镜头同序重绘；其中 3 条共用**同曲不同录音版**音轨（rules 第35条 路线③）。

**六步流程（路线 A，主推）**：
1. `tools\成片拆解.py -i "<原片>" --asr` 出**切点表**（= 切段表）；
2. 定声音路线（rules 第35条 四选一；可用 `tools\成片对比.py -a "<同款二创>" -b "<原片>"` 反查别人走的哪条）；
3. **剪映预处理**：按切点切段（每段 2–8s）→ **单人物化**（作者原话："我怕生成出来角色错误，我剪映剪了一下，只有一个人物"）→ 字幕/水印用大黑块盖住 → 段文件带时间码；
4. 逐段替换生成（输入=该段视频，必要时 + 目标角色图），提示词用下面的骨架；
5. 每段**抽 2–4 张**，按段质检（形象 / 表情时机 / 形变保留 / 单人物 / 无文字 / 时长 / 镜头），通过即锁定，废段单独重跑；
6. 剪映接回时间线 → 响度统一 → 机器复核（`成片拆解.py` 查多出人物/文字；`成片对比.py` 查画面是否同轴）。

**提示词骨架（"原片直投替换"版；第三方作者实测口径 + 本 skill 锁定句）**：

```
【替换】画面中的人物替换为{目标角色}，与@图片1完全一致（面部、发型、服装、体型比例）。
【表情同步】角色必须完全模仿原视频人物的全部动作和表情，尤其是表情变化必须完全同步保留：
原视频人物出现什么表情（惊讶、震惊、害怕、愤怒、开心等），替换后的角色都必须做出完全相同的表情、表情变化和变化时机。
【动作与形变】完整保留原视频中的所有动作效果和身体变化，包括夸张动作、弹性效果、身体拉伸、胳膊拉长、身体变形等；
原视频人物身体如何运动、拉伸、变形，替换后的角色必须完全按照原视频同步模仿，不恢复成正常人体动作。
【锁定】除人物（和{道具}）外，镜头、运镜、构图、人物位置、动作节奏、体型比例、背景、光影全部保持不变。
【单人物】画面中不得出现原片其他人物、不得新增任何人物。
【无文字】画面无任何文字、字幕、水印；被遮挡的字幕区域用与周围一致的正常画面自然补全。
【声音】{沿用原片原声，不重新配乐 / 保持静音}；【时长】与输入视频等长。
不要生成水印，不要生成Logo。
```

> **与 rules 第32条（替换类宜短）的关系**：短版（分工三句 + 锁定句）适用于"素材分工明确"的路线（深度片 / 遮罩片 / 图层面替换）；本骨架较长，是因为**原片直投**时模型必须被显式约束"表情与形变跟着原片走"，否则会自创表演。两版并存，按输入形态选。

**抽卡经济学（对治"整片一次替换、抽 50 次成功 1–2 次"）**：
- 整片一次替换的失败**不可定位**；分段后单段独立抽卡，废段只重跑该段；
- 失败归因判据：**每次失败原因不同**（形象漂 / 多人物 / 出文字）→ 模型波动，继续抽有效；**每次失败原因相同**（始终替换不动）→ 输入或提示词有结构性问题，**换路线（图层面替换 / 遮罩片）而不是继续烧积分**。

**依据**：①B站 `BV1kuKE66Eds` 四步流程（拆分→按镜头切段→只改人物→逐段生成接回）；②本机两组拆解实测（`AI视频素材\参考1-4_二创拆解对比.md`、`AI视频素材\琵琶曲拆解\琵琶曲_二创拆解对比.md`）；③第三方作者「雨霖下雨了」提示词原文与"剪映只留一个人物"做法（`${SAMPLES_ROOT}\_范本调研_2026-09-12\第三方作者提示词_雨霖下雨了_MV换人.md`）。
