# 回归用例（evals）：改规则之后照这个跑一遍

**方法来源**：ModelScope《skill-creator》（2026-09-11 抄录，`https://www.modelscope.cn/skills/@anthropics/skill-creator`）——
它的核心是"写草稿 → **造测试题** → 跑一遍（含对照）→ **逐条断言** → 按结果改"，而不是凭感觉改措辞。
本文件把它落成本 skill 的最小可用版。

**用法**：改完 `rules.md` / `rules.local.md` / `prompt-templates.md` 之后，让一个**只读本 skill** 的 agent 依次处理下面 8 条输入，
逐条勾断言；**任何一条不达标就回去改规则，不要靠"我觉得这样写更好"**。新增失败案例时补一条用例（见文末）。

---

## 用例 1 · 口播带货（含读音敏感词）

**输入**：`给现有项目的老师形象写一条 12 秒的口播提示词，台词里要念"四六级"，用参考音频8 当音色`

**断言**：
- [ ] 画幅句写 `9:16竖屏`（规则26，**不写**"与源片同画幅"）
- [ ] 按台词时长/素材组合选模型并说明（规则17）
- [ ] 音色参考用 **3.5s 短版**（不做长版铺满）
- [ ] 每个镜头单元都带负面词（无字幕 / 无运镜）（规则1）
- [ ] 台词固定句 + 引号逐字（规则3）
- [ ] **"四六级"必须配音驱动**，并写明"四立级/四留级/66级=真错；46级=待定需耳朵确认"（规则15 + L1/L7）

## 用例 2 · 横版源转竖版

**输入**：`我这条参考视频是 16:9 的，但我要竖版成片，怎么写？`

**断言**：
- [ ] **不**让模型在提示词里"转竖版"当主要手段
- [ ] 先给本地预处理：`tools\竖版画布.py`（crop 满屏 / pad 保构图，二选一说明适用场景）（规则26）
- [ ] 提示词画幅句写 9:16 + 几何句（画面完整保留、不裁切不放大、镜头静止、人物大小位置不变）
- [ ] 若走替换类，提醒提交设置**手选 9:16**（规则26/29：画幅由提交设置决定）

## 用例 3 · 换人（L4 单主体替换）

**输入**：`把这条参考视频里的人换成这个三视图角色，保持她的动作`

**断言**：
- [ ] 先讲清 L4 难点（规则20b/24：通用模型不擅长"换内容"），**不承诺一次成功**
- [ ] 给出**平台内路线**：深度视频信息过滤（规则30）或图片驱动（规则17 形态）
- [ ] 提示词含反向排除句：`只参考动作…不要参考它的黑白画面、人物身份和原始场景`
- [ ] 提示词**短**（规则32：分工三句 + 锁定句，约 200–400 字，不写新的表演内容）
- [ ] 结尾单独一句 `不要生成水印，不要生成Logo。`（规则29）

## 用例 4 · 复刻动作 + 换环境

**输入**：`这段 20 秒的舞蹈视频，我想复刻动作但换人换环境`

**断言**：
- [ ] 建议先转深度视频：`tools\深度视频.py -i "<源片>" --segment 15`（规则30 + `references/depth-video-setup.md`）
- [ ] 三素材分工：驱动视频只管动作 / 人物图只管角色 / 场景图只管环境
- [ ] 15 秒以内切分（规则17/30）
- [ ] 说明深度路线在即梦的实测结果（技术指标可对、画面仍可能不达标，见规则30 实测记录）

## 用例 5 · 原生实拍感

**输入**：`我想要那种被路人用手机拍到的感觉，别太精致`

**断言**：
- [ ] 切**B 档运镜**（允许轻微不规则手持抖动），**不是** A 档"全程绝对无运镜"（规则31）
- [ ] 三连负面齐全：`不要剧烈摇晃、不要突然变焦、不要切镜`
- [ ] 配真实感元素：现场收音 / 画外人群反应 / 设备点名（iPhone 直拍）

## 用例 6 · 微表情与情绪

**输入**：`这句台词"你怎么才来"，人物要委屈一点，给我写表演`

**断言**：
- [ ] 用情绪拆解公式：动机+眼神+呼吸+脸部+身体+声音+收尾（规则27）
- [ ] **无**环境人物 / 空间位移（"看向某人""走到桌前"→ 改成镜头方向或保持原景别）
- [ ] **无**心理描写（"心里委屈"→"眼睑微压、呼吸停滞"）
- [ ] 2–3 秒切片内最多 1–2 个极微小动作，带"缓缓/极轻微"降速词

## 用例 7 · 提交前核对

**输入**：`我要提交了，提醒我该检查什么`

**断言**：
- [ ] 四项硬核对：**比例 9:16** / 分辨率 / 时长 / 这一轮挂几个素材（含"不挂音频"这类）
- [ ] 提醒**不代提交**（规则13 + 工作区铁律：生成前必须汇报、拿到明确同意）
- [ ] 提醒只抽 1 张先验证，不宜一次抽多张（规则32 的对照思路）

## 用例 8 · 提示词该写多长

**输入**：`这个替换类的提示词是不是写得越长越好？`

**断言**：
- [ ] 明确回答"**不是**，宜短"（规则32）
- [ ] 给出三块结构：素材分工 + 反向排除 + 锁定句
- [ ] 说明机制：写进去的表演描述会被模型当成新创作指令
- [ ] 说明保留条件：短版出现"多文字/多出人/新增表演"时再上锁版，两版对照抽卡

---

## 维护

- **触发时机**：每次提交 `references/rules*.md` / `prompt-templates.md` 的改动后跑一遍；新规则入库时同步补用例。
- **新增用例**：把"真实失败案例"写成用例（输入 + 当时的错误表现 + 期望断言），比写抽象规则更能防回归。
- **对照（可选）**：同一条输入跑两遍——一次带 skill、一次不带——看差异是否来自 skill，而不是模型的通用能力（skill-creator 的 baseline 思路）。
