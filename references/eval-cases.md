# 回归用例（evals）：改规则之后照这个跑一遍

**方法来源**：ModelScope《skill-creator》（2026-09-11 抄录，`https://www.modelscope.cn/skills/@anthropics/skill-creator`）——核心是"写草稿 → **造测试题** → 跑一遍（含对照）→ **逐条断言** → 按结果改"，而不是凭感觉改措辞。

**用法**：改完 `rules.md` / `rules.local.md` / `prompt-templates.md` 之后，让一个**只读本 skill** 的 agent 依次处理下面 12 条输入，逐条勾断言；**任何一条不达标就回去改规则，不要靠"我觉得这样写更好"**。新增失败案例时补一条用例（见文末）。

**记号**：L1–L4＝替换难度分级；L1 物件替换 / L2 台词替换 / L3 同人造型替换 / L4 人物替换进原片（详见 `references/playbooks.md` 第一部分）。

---

## 用例 1 · 口播带货（含读音敏感词）

**输入**：`给现有项目的老师形象写一条 12 秒的口播提示词，台词里要念"四六级"，用参考音频8 当音色`

**断言**：
- [ ] 画幅句写 `9:16竖屏`（规则26，**不写**"与源片同画幅"）
- [ ] 按台词时长/素材组合选模型并说明（规则17）
- [ ] 音色参考用 **3.5s 短版**（不做长版铺满）
- [ ] 每个镜头单元都带负面词（无字幕 / 无运镜）（规则1）
- [ ] 台词固定句 + 引号逐字（规则3）
- [ ] **"四六级"必须配音驱动**，并写明"四立级/四留级/66级=真错；46级=待定需耳朵确认"（规则15 + L1/L7）

## 用例 2 · 横版源转竖版

**输入**：`我这条参考视频是 16:9 的，但我要竖版成片，怎么写？`

**断言**：
- [ ] **不**让模型在提示词里"转竖版"当主要手段
- [ ] 先给本地预处理：`tools\竖版画布.py`（crop 满屏 / pad 保构图，二选一说明适用场景）（规则26）
- [ ] 提示词画幅句写 9:16 + 几何句（画面完整保留、不裁切不放大、镜头静止、人物大小位置不变）
- [ ] 若走替换类，提醒提交设置**手选画幅**（默认 9:16，按需横屏/方屏；规则26/29：画幅由提交设置决定；本机 L10 另有裁定时从其规定）

## 用例 3 · 换人（L4 单主体替换）

**输入**：`把这条参考视频里的人换成这个三视图角色，保持她的动作`

**断言**：
- [ ] 先讲清 L4 难点（规则20b/24：通用模型不擅长"换内容"），**不承诺一次成功**
- [ ] 给出**平台内路线**：深度视频信息过滤（规则30）或图片驱动（规则17 形态）
- [ ] 提示词含反向排除句：`只参考动作…不要参考它的黑白画面、人物身份和原始场景`
- [ ] 提示词**短**（规则32：分工三句 + 锁定句，约 200–400 字，不写新的表演内容）
- [ ] 结尾单独一句 `不要生成水印，不要生成Logo。`（规则29）

## 用例 4 · 复刻动作 + 换环境

**输入**：`这段 20 秒的舞蹈视频，我想复刻动作但换人换环境`

**断言**：
- [ ] 建议先转深度视频：`tools\深度视频.py -i "<源片>" --segment 15`（规则30 + `references/playbooks.md` 第三部分）
- [ ] 三素材分工：驱动视频只管动作 / 人物图只管角色 / 场景图只管环境
- [ ] 15 秒以内切分（规则17/30）
- [ ] 说明深度路线在即梦的实测结果（技术指标可对、画面仍可能不达标，见规则30 实测记录）
- [ ] **多主体同框的转绘**另有正面证据（规则54：5 人换同一角色＋换直播间背景＋复现屏上文字，视觉侧全达标）——**不要拿规则24 的旧结论直接否掉深度片**

## 用例 5 · 原生实拍感

**输入**：`我想要那种被路人用手机拍到的感觉，别太精致`

**断言**：
- [ ] 切**B 档运镜**（允许轻微不规则手持抖动），**不是** A 档"全程绝对无运镜"（规则31）
- [ ] 三连负面齐全：`不要剧烈摇晃、不要突然变焦、不要切镜`
- [ ] 配真实感元素：现场收音 / 画外人群反应 / 设备点名（iPhone 直拍）

## 用例 6 · 微表情与情绪

**输入**：`这句台词"你怎么才来"，人物要委屈一点，给我写表演`

**断言**：
- [ ] 用情绪拆解公式：动机+眼神+呼吸+脸部+身体+声音+收尾（规则27）
- [ ] **无**环境人物 / 空间位移（"看向某人""走到桌前"→ 改成镜头方向或保持原景别）
- [ ] **无**心理描写（"心里委屈"→"眼睑微压、呼吸停滞"）
- [ ] 2–3 秒切片内最多 1–2 个极微小动作，带"缓缓/极轻微"降速词

## 用例 7 · 提交前核对

**输入**：`我要提交了，提醒我该检查什么`

**断言**：
- [ ] 四项硬核对：**比例** / 分辨率 / 时长 / 这一轮挂几个素材（含"不挂音频"这类，以及参考视频是否已静音且画幅正确）
- [ ] 提醒**不代提交**（规则13 + 工作区铁律：生成前必须汇报、拿到明确同意）
- [ ] 提醒只抽 1 张先验证，不宜一次抽多张（规则32 的对照思路）

## 用例 8 · 提示词该写多长

**输入**：`这个替换类的提示词是不是写得越长越好？`

**断言**：
- [ ] 明确回答"**不是**，宜短"（规则32）
- [ ] 给出三块结构：素材分工 + 反向排除 + 锁定句
- [ ] 说明机制：写进去的表演描述会被模型当成新创作指令
- [ ] 说明保留条件：短版出现"多文字/多出人/新增表演"时再上锁版，两版对照抽卡

## 用例 9 · AI 二创拆解

**输入**：`我发你一条 AI 二创成片，你先拆一下它是怎么做的`

**断言**：
- [ ] 走 `references/playbooks.md` 第二部分流程：**先机器证据**（`tools\成片拆解.py -i "<成片>" --asr`），不凭肉眼直接下结论
- [ ] 跑**读片三问**（规则33）：节奏跟不跟音乐 / 人物镜头稳不稳 / 口型是否逐段配，并给出证据（切点数、对齐率、位移）
- [ ] 出《拆解报告》八节（含时间轴分段表、保留/替换清单、复现路线、风险与不确定项）
- [ ] 报告先交付、**复现路线等用户决定**；同时说明**不代提交生成**（规则13）
- [ ] 版权与素材授权先提示（规则7）；作者口径与本机实测分开标注
- [ ] 若判为音乐驱动 → 下单走规则33–36（声音先行）+ 模板 D

## 用例 10 · 音乐二创/翻唱类提示词

**输入**：`把这段"华强买瓜"台词做成迪士尼音乐剧版的二创，怎么写提示词？`

**断言**：
- [ ] **声音先行**：先给作曲/演唱指令，再谈画面（规则33）
- [ ] 台词**一字不改**、不翻译、不改顺序；作曲指令含「旋律贴合声调」（规则35）
- [ ] 音频（歌）按**原片镜头切 1–2 句一段**，逐段配口型，最后接回时间线（规则34）
- [ ] 保留/替换清单明确：站位·镜头角度·背景·台词原句=保留；服装/发型/妆造/表演状态=替换（规则36）
- [ ] **不写新剧情**；字幕属后期不写进生成提示词
- [ ] 光影不统一时提「全景空镜 + 局部重绘」（规则37，注明待验证）

## 用例 11 · MV/音乐类换人替换

**输入**：`我想把这条 MV 里的角色换成我们的角色，之前整片替换抽 50 次才成 1–2 次，怎么办？`

**断言**：
- [ ] 明确指出**不要整片一次性替换**（规则38）；给"按切点切段（2–8s）→ 单人物化 → 逐段抽卡"的流程
- [ ] 切段依据来自 `tools\成片拆解.py` 的切点表；字幕/水印用大黑块遮挡
- [ ] 提示词含：替换句 + **表情同步句** + **动作与形变保留句** + 锁定句 + 单人物排除句 + 无文字水印句 + 声音/时长句（playbooks.md 第一部分 1.5 节）
- [ ] 说明与规则32 的关系：原片直投用长框架、素材分工路线用短版
- [ ] 给**失败归因判据**（原因每次不同→继续抽；原因相同→换路线），并提示换路线走规则23 图层面替换
- [ ] 声音路线四选一（规则35）；引用一致性、不代提交等既有硬项不遗漏

## 用例 12 · 笑容闸门（表情过度：笑容偏多、表情过度的惯性）

**输入 A（叙事型带货）**：`这段播音稿讲课程机制和赠品，帮我配表演，老师是叙事口吻`

**断言（输入 A）**：
- [ ] **正向笑容描写 0 处**（不写"笑着/微笑/笑意/眼睛弯起/眼睛亮起来"）；注意 L6 的反向压制句 `不要刻意微笑` **必须留着**，不计入此数
- [ ] 面部只写收敛句：`面部表情自然，只随语气有极轻微变化`（规则39）
- [ ] 表情形容词 ≤1 个（**反向压制句里的 `不要挑眉`/`不要瞪大眼睛` 不算**）；**无**"表情细腻有层次/手势丰富灵动"这类禁用词（L6）
- [ ] 笔墨落在**动作细节**：手/物件/身体位移/节奏停顿，逐句对应台词（规则3 + 规则39）
- [ ] 负向压制句仍在：`不要刻意微笑` 一类固定加（L6）

**输入 B（调侃段落）**：`这段是玩梗自嘲，损学生三天打鱼两天晒网，怎么配表情`

**断言（输入 B）**：
- [ ] 笑意只出现**1 个动作单元**（`嘴角极轻扬一下` / `带笑带刺`），且写明"随即收起、下一句回到自然"；字符计数不必为 0，但不得每句都笑
- [ ] 其余句仍走收敛表情
- [ ] 情绪走规则27 三禁忌：无环境人物/无空间位移/无心理描写；2–3 秒切片内 ≤1–2 个极微小动作

**输入 C（漫剧方向）**：`这条是漫剧剧情向，角色有哭有笑，按剧情来`

**断言（输入 C）**：
- [ ] 按剧本情绪给笑容，但**以台词情绪为准**，不默认加笑（规则39）
- [ ] 大表情只留情绪峰点，其余用微表情组合（规则27）

**输入 D（人设未给）**：`这条片子的主体是谁、性格怎么样你看着办`

**断言（输入 D）**：
- [ ] **不预设人设**——先请用户给主体身份/情绪基调（人设是项目参数，规则19/39）
- [ ] 只保留"表演幅度"的默认（表情收敛、动作写够），不替用户定性格
- [ ] 不因为对方没说就把主体默认成"老师/带货博主"

## 用例 13 · 音色参考自读（真实失败案例：配音多念了一部分）

**输入**：`台词是"9月19日晚七点，抽9块9真题卷和我手上的日历，还抽免单，同学们别忘了来吆"，用参考音频9 当音色，写一条 14.5 秒的替换类提示词`

**当时的错误表现**（`青海摇替换` v1，2026-09-17）：提示词写死"口播落在 0.5–8.0 秒说完"，成片却把句尾的「免单」念了**两遍**
（5.88–6.58 与 7.92–8.80）、人声拖到 **10.78s** 才结束、中段多出 **1.34s 停顿**；用户判废，废因＝「配音额外多了一部分」，
六维判语速「偏快或偏慢」。

**断言**：
- [ ] 台词固定句含「不得改词、不得漏句、不得添加、**不得重复任何词**」（规则52 + 模板 C2b）
- [ ] **不把口播秒数当约束**：写了秒数要说清"这是给剪辑的参考"；要卡死时间与逐字内容 → 改**整条配音驱动**（规则52/15）
- [ ] 交付带一句"成片后逐字过耳核一遍配音"（规则15）
- [ ] 报预估时长按实测口径留余量（自读可能低到约 3 字/s：本例 34 字实际用了 10.78s）（规则52）
- [ ] 画面里**必须出现文字**时（大屏 / 包装 / 横幅），负面写「除@图片N 上原有的文案外，不要出现任何其它文字」，
      **不写光秃秃的"不要出现任何文字"**（规则53）

## 维护

- **触发时机**：每次提交 `references/rules*.md` / `prompt-templates.md` 的改动后跑一遍；新规则入库时同步补用例。
- **新增用例**：把"真实失败案例"写成用例（输入 + 当时的错误表现 + 期望断言），比写抽象规则更能防回归。
- **对照（可选）**：同一条输入跑两遍——一次带 skill、一次不带——看差异是否来自 skill，而不是模型的通用能力（skill-creator 的 baseline 思路）。
