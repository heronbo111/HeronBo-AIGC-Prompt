# 样本库（提示词 → 成片 → 评价）

> 本库随反馈持续更新：每次有新反馈（六维评价 json / 口头规律 / 废片原因）按 SKILL.md「反馈优化循环」四步更新。规则详见 `rules.md`，模板详见 `prompt-templates.md`。

根目录：`${SAMPLES_ROOT}`（取值见 `references/paths.local.md`；首次由用户指定项目位置时写入）
每条实验一个文件夹：

```
<实验名>/
├── 文案/口播稿.txt    # 台词原文（上游产物）
├── 文案/提示词.txt    # 生成指令（含 UUID 映射表，如适用）
├── 素材/              # 参考图/音视频
├── 平台上传/          # 交付时的上传副本 + 上传说明.txt
├── 成片/              # 验收成片
├── 废片/              # 作废抽卡（文件名=项目-版本-废因）
├── 评价/*.json        # 六维评价（评分工具产出）
└── 备注/备注.txt      # 主观备注 + 生成参数
```

评分工具：skill 包内 `tools\score_gui.cmd`（优先 `dist\score-tool.exe`）。窗口里选样本 → 选成片 → 六维/违禁项点分 → 保存到对应样本 `评价/`；本库每样本的「评价」行 = 最新一条 json 的摘要。
新样本按此结构收录；生成参数缺失=信息丢失，收集时优先补。

**术语**：样本名用「示例-XX」或主题名表示；六维＝口型 / 动作 / 形象 / 语速 / 节奏 / 违禁项（字幕、运镜、畸变）。
