# 样本库（提示词 → 成片 对照）

> 本库随反馈持续更新：每次有新反馈（六维评价 json / 用户口头规律 / 废片原因）按 SKILL.md「反馈优化循环」四步更新，规则详见 rules.md，模板详见 prompt-templates.md。

根目录：`${SAMPLES_ROOT}`（取值见 `references/paths.md`）
每条实验一个文件夹（2026-09-08 定型）：

```
<实验名>/
├── 文案/口播稿.txt    # 台词原文（上游产物）
├── 文案/提示词.txt    # 生成指令（含 UUID 映射表，如适用）
├── 素材/              # 参考图/音视频
├── 成片/              # 验收成片
├── 废片/              # 作废抽卡（文件名=日期-废因）
├── 评价/*.json        # 六维评价（网页工具产出）
└── 备注/备注.txt      # 主观备注 + 生成参数
```

评价工具：skill 包内 `tools\启动评分工具.bat`（localhost:8787）。启动后浏览器连接样本目录（自动记忆），勾选六维保存到对应样本 `评价/`；本库每样本的「评价」行 = 最新一条 json 的摘要，统计参考网页统计面板。
新样本按此结构收录；生成参数缺失=信息丢失，收集时优先补。
