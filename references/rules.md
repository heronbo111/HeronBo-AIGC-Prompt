# 硬规则与已验证的教训

全部来自 2026-09 三组真实样本（示例-大礼盒促销 / 示例-直播空降 / 示例-影视替换）的生成经验。写提示词前必读。

## 1. 负面词每段写死

- `不要有任何字幕`（用户原话：不要有任何文字！）
- `全程绝对无运镜`
- `无AI畸变`

**为什么**：大礼盒备注教训——「这次效果很好，但是提示词忘写不加运镜和不生成字幕导致有个很好的抽卡被放弃了」。抽卡画面好但带着运镜/字幕，整条作废。负面词不是开头写一次就完，**每个镜头单元都要带**。

## 2. 人物与场景锚定

- 人物图（形象参考）+ 一段逐字复用的描述（如「短黑发戴眼镜女老师，浅灰色衬衫」），多段之间禁止措辞变化——措辞一变模型就漂移
- 场景描述同样逐字复用（如「红底促销直播背景板+黑色桌面，固定中景正对镜头」）
- 光线：`画面光线明亮均匀，与参考视频完全同画质同色调`
- 多段时用同一张人物图作为跨段锚（模型保证不了"完全承接"的文字承诺，图片锚定才是硬保障）

## 3. 动作-台词一一对应，动作前置

写法：「动作描述 + 台词引号」成对小节，一行一个动作，例如：

> 边摊手边轻轻摇头吐槽"便宜的时候你不买"；眼睛亮起来身体微微前倾笑着接"这下好了，终于被你等到了"

**为什么**：动作前置的对应表让模型"没得猜"；台词后括号标注（如"我的盒子（拿起晃一晃）"）模型执行不稳定。Sample：即梦 agent 三段式全部用动作前置。

## 4. 分段规则（多段分镜）

- **≤ 所选模型单次上限不分段，一次生成**（默认 seedance2.0fast：15s；seedance2.5：30s；写前现查 `dreamina multimodal2video -h`）
- 超上限才按**语气拐点**切镜头单元（吐槽→揭晓→卖点这类情绪转折处；每单元 8–13s 留余量），不在句子中间硬切
- 段间承接只写 4 个锚点：人物形象 / 背景环境 / 人物位置 / 持盒状态；描述句逐字复用第一段
- 分镜单元是"完整镜头"（可跳切拼接），不是"把一段话分成三截"

## 5. 音频的两种角色（必须区分）

| 角色 | 特征 | 用法 | 样例 |
|---|---|---|---|
| **台词配音** | 一段完整口播，时长 ≈ 整条成片时长 | 音频驱动口型，视频时长由音频决定 | 大礼盒 参考音频7.mp3（13.9s→成片 14s） |
| **音色参考** | 短采样（几秒），无台词或非整段 | 只定音色，视频时长由提示词文字驱动 | 空降 音频1–5（各 ~4.8s） |

区分方法：音频能不能覆盖整条台词。不确定时问用户。

## 6. 素材精简

**为什么**：「素材太多太杂影响ai判断，和原片没有保持百分百一致」——素材多不等于信息多，模型在多参考之间互相打架。一条实验：角色一张图、产品一张图、音频一个角色一个样例，多出来的放"备用"标注用途。

## 7. 版权/过审（参考视频类特有）

- 影视片段复刻大概率卡版权审核；规避处理能过审但 AI 参考效果大幅打折——**任何过审技巧要记录代价**，未采用的新思路直接标记「未验证」
- 文件名带"试验/恶毒"的都是实验素材，分析时不要当正式样本定论

## 8. 可复现性

- 即梦网页编辑器的 `@UUID` 资产引用（如 `@图片1-d009-…`）脱离网页不可复现——样本里要同时标注每个 UUID 对应的本地文件
- CLI 提交用文件路径，提示词/注释里给素材清单（路径+角色）
- 生成参数（模型版本/时长/画幅/分辨率/抽卡次数/入口）没记的就是丢失信息，补录优先

## 9. 已经生效的正面词（seedance2.5 已验证）

- 「具有参考视频节奏，以画面变化为核心」「保持与@xxx 百分百一致」这类强绑定表述在**参考视频类**有效
- 「无AI畸变」「自然松弛的直播口播状态」「亲切感」对真人口播成片质感有效
- 台词强调用引号内文字+（强调）注记比大写全角感叹号更稳

## 10. 引用一致性（2026-09-08 血泪教训：作废了1条的2.5成片）

**提示词里写到的每一个"@视频1 / @图片1 / 参考视频"都必须真实存在于提交输入中。**

- **生成类（图片+音频驱动）提示词禁止写"参考视频/视频1/与视频X同画质同色调"**——传了什么才能引用什么；模型会试图对齐一个不存在的参考，导致口型台词完全对不上、动作不流畅、整条作废（用户原话：这种生成类的不要参考视频，会出入很大）
- 引用来源只有三种：已上传图片标题（如图片1=人物形象.png）、已上传音频、已上传视频（仅参考视频类用）
- 教训实录：2.5 任务（待补）提示词写"完全参考视频1"但未传任何视频 → 口型台词对不上、动作不流畅，用户判定完全不能用

## 11. 素材识别先行（2026-09-08 果冻广告反馈）

**写提示词前必须先识别素材内容**（抽帧统计/用户确认），不能套模板套死：

- **主体数量**：模板 C 常见的"其余演员和场景保持原样"只在**多主体**时使用；视频只有一个主体时，删除该句（用户反馈：视频中只有一个主体，提示词带"其它演员"是错误）
- **背景色**：用 ffmpeg 抽帧平均色确认真实背景色（果冻广告=深蓝紫星空 RGB≈88/85/105，B 通道最高），提示词里写"从`实际色`切换为产品主色"而不是空泛描述
- **上限裁剪**：原片超模型上限（2.0fast 15s）时，**优先倍速（setpts+atempo，如 1.5x）压到 ≤15s** 再上传，保动作节奏；倍速输出命名带参数（如 `果冻广告_1.5x_14.5s.mp4`）
- 引用的 @视频1 指向**裁剪后文件**，素材清单写明路径

**Why:** 用户 2026-09-08 反馈："给你的素材你需要进行识别，像视频中只有一个主体，你的提示词还带上了其它演员干什么"——模板句式照抄套用的直接教训。

## 12. 替换类·无台词片的两条硬规则（2026-09-08 果冻广告首版作废教训）

用户实测（jimeng-2026-09-08-4026 成片）：跳舞僵硬、BGM 奇怪、礼盒没有形变——整条不能用。

- **拟人化形变必须显式写**：用硬质产品（礼盒/书/盒子）替换**软体弹性角色**（果冻/卡通）时，只写"完整复刻动作"会得到刚体平移（僵硬）。必须写明：主体像原片角色一样**Q弹软体化**——拉伸、弯曲、扭动的弹性形变，摆动跟上节拍，姿态活泼，"绝不能像硬纸盒一样僵硬平移"
- **音乐必须显式写"沿用原片原声"**：提示词不提音乐，模型会自配奇怪 BGM。写法：`背景音乐完全沿用@视频1的原片原声，不要重新配乐、不要添加任何新的音效`
- 动作描述升级：不要只写"百分百一致"（模型执行偏机械），要拆成"完整复刻整段动作编排——跳舞、转身、挥手、节奏卡点一一对应" + 形变风格要求

**Why:** "复刻动作"≠"复刻质感"。替换类 transferring 的是动作编排，角色的材质特性（软/硬/弹性）必须单独声明，否则模型按物理直觉渲染刚体。

## 13. 交付边界：只出提示词，永不出现 CLI/报价（2026-09-08 用户指令）

用户原话："以后不要再出现这个，你不是已经断开了cli吗，只生成提示词，写死进skill里"——即梦 CLI 已断开，**交付物 = 提示词正文 + 素材清单（+拼接说明/收稿时长标注）**，交付中禁止出现：CLI 命令、积分/价格、队列等待、提交方式配置。提交生成由用户在即梦网页完成。

**交付后固定动作**：主动问询打分 + 打开评分网页（本包 `tools\启动评分工具.bat` → localhost:8787；样本目录在页面选择一次即记忆，不用每次手选）。收到评价反馈后按「反馈优化循环」四步更新，并**询问用户是否按此反馈优化 skill**。本机路径统一见 `references/paths.md`（换机只改该文件）。

**Why:** 2026-09-08 四六级实验交付中混入「报价与队列」段和 CLI 提交命令，被用户点名纠正——提示词与提交是两个环节，提示词环节不掺提交的事（承接 rules.md 第10条「引用一致性」的同类教训：写了不存在的东西就作废，说了不该说的同样是噪音）。

## 14. 音色参考必须是独立音频资产；参考视频要静音输入（2026-09-08 四六级首版成片教训）

**「音色参考=参考视频自有原声（不单独传音频）」失效**：模型把视频当画面参考，不锚定其音色，默认用自带女声——听感"换人"，用户判定"台词不一致"。实测：原片口播中位 F0=154Hz（四分位[136,190]），生成成片 F0=195Hz（[162,264]），明显偏高一档的年轻女声；而台词转写逐字正确、画面形象一致。

修复形态（=空降样本已验证路径 + 2.0fast 输入约束）：
- **音色参考=独立短音频**（2–3s 纯人声，如 @音频1 直接指向它），不混在视频里；
- **参考视频静音后上传**（原声台词与提示词引号台词并存会让模型在"念什么"上打架，首版只是侥幸对了）；2.0fast 输入单条/总计≤15s → 视频 12s + 音频 3s = 15s 刚好。
- 引用一致性写法：提示词里"音色完全参考@音频1（参考人物的说话声音）"，画面参考仍指@视频1。

**动作库来自原片观察，禁止自创大动作**：首版 6s 成片出现"抬红杯举到脸前挡嘴"——提示词虚构了原片没有的动作（原片全程捧杯不动），模型执行过猛。动作小节应逐条对照抽帧后原片的能力范围（点头/挑眉/眼神/微前倾）编写，不做原片没有的抬手/举物。
