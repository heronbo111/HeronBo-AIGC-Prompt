# 路径约定（本机取值由用户指定）

skill 正文一律使用变量名（`${SAMPLES_ROOT}` / `${AI_CREATE_ROOT}`），不写死任何具体路径。
**本文件就是本机取值表：首次使用时由用户指定，不预设任何默认路径。**

## 首次使用：先问用户，不要猜

agent 必须先原样问一次：

> 请问您要把项目建在哪里？您提供好素材后，我会自动将其进行归类

拿到位置后：① 建项目骨架（`文案/素材/成片/废片/评价/备注`，交付提示词时再加 `即梦上传/`）；② 把用户提供的素材/文案自动归类落位；③ 把下表两个变量填成实际路径（或直接跑 `python tools\首次配置.py --project "<项目目录>"`）。
用户没给明确位置时**再问一次**——不得自己猜，也不得创建默认目录（旧版自动建 `%USERPROFILE%\AI创作\提示词skill生成尝试` 的行为已废弃）。

| 变量 | 含义 | 本机取值（用户指定） |
|---|---|---|
| `${SAMPLES_ROOT}` | 样本库根目录 = 各项目目录的上一级（评分网页连接这一级；素材库/成片/评价都在其下的项目目录里） | `<待用户指定>` |
| `${AI_CREATE_ROOT}` | 参考素材/来源素材根目录（原片、音色参考等外部素材所在位置） | `<待用户指定>` |

## 目录模型（样本库内含素材库）

```
${SAMPLES_ROOT}/
└── <实验名>/
    ├── 文案/      口播稿.txt、提示词.txt
    ├── 素材/      用户提供的参考图/产品图/音频/原片（agent 自动归类，保留原文件名）
    ├── 即梦上传/  交付提示词时同步生成的副本 + 上传说明.txt
    ├── 成片/      验收成片
    ├── 废片/      作废抽卡（文件名=日期-废因）
    ├── 评价/      评分网页产出的 *.json
    └── 备注/      备注.txt（主观备注 + 生成参数）
```

## 首次使用 / 换机清单

1. 安装 skill：ZCode `~/.zcode/skills/`；Codex CLI `~/.codex/skills/`；DeepSeek Harness `~/.dsh/skills/`（也可项目级 `.dsh/skills/`）。新对话自动识别。
2. agent 问用户「请问您要把项目建在哪里？您提供好素材后，我会自动将其进行归类」→ 建骨架 + 归类素材 + 填本表。
3. 评分工具：双击 `tools\启动评分工具.bat`（首次点「连接样本目录」选中 `${SAMPLES_ROOT}`，之后自动记忆）。依赖 Python 3（在 PATH）。
4. 环境：Edge/Chrome + ffmpeg（素材识别抽帧用）+ 即梦账号（生成在网页完成；CLI 已断开，本 skill 不代提交/不报价）。
5. 自检：`python -m http.server 8787 --directory <本包 tools 路径>` → 打开 `http://localhost:8787/评价工具.html`，能连目录、能打分、能保存 json。
