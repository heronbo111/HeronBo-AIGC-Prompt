# 提示词模板（四大类 ↔ 模板）

模板结构来自真实样本与平台 agent 三段式。每个模板给出：骨架 + 完整示例 + 注意事项。本文件只供提示词设计，不含 CLI 命令/价格。

## 四大类 ↔ 模板对应表（先定类，再取模板）

| 大类 | 判定信号（用户给什么 / 要什么） | 模板 | 图/视频/音频引用上限 | 关键差异 |
|---|---|---|---|---|
| **图生视频** | 给图（形象图/首帧/尾帧/四视图），无参考视频；要"让它动起来" | **A** 单段 / **B** 多段 / **C2b** 图片驱动双替换 | 只引用真实上传的 @图片 / @音频；**禁止写"参考视频/视频1"** | 图片是唯一锚；道具替换走这条 |
| **文生视频** | 什么都不给，只有一段文字 | **F**（**未验证**） | 无任何 @引用 | 人物/场景/动作/镜头/风格全靠文字；一致性靠描述词逐字复用 |
| **参考视频生视频** | 给参考视频，要"照它的运镜/动作/节奏" | **C**（C1 全片替换 / C1b 两段式 / C2 局部替换） | @视频1 = 动作节奏；可 +@音频（音色参考） | 画面内容自己写，动作节奏跟 @视频1 |
| **参考视频替换生视频** | 给原片 + 要"把里面的人/物换掉" | **C1**（商品拟人化）/ **C2** / **E**（分段多主体） | @视频1 = 原片；+@图片N 替换源 | 锁机位构图与镜头节奏，只换表现层；难度 L1–L4 |
| （音乐二创/翻唱） | 给音乐，要卡点/配口型 | **D**（D1 作曲 / D2 关键帧 / D3 逐段口型） | @图片1 关键帧 +@音频1 音频段 | 参考视频类的特例；声音先行 |

**符号说明**：L1＝物件替换（商品/道具拟人化）、L2＝台词替换（画面全保留）、L3＝同人造型替换（换装/换手中物）、L4＝人物替换进原片（换人并复刻原片动作/镜头/场景）。分级依据与工具选型见 `references/playbooks.md` 第一部分。

## 0. 模型选择（**由用户自己选**）

- **不按台词时长自动选模型**：档位以用户自己的选择为准；agent 每次出提示词**只告知本条预计需要多少秒**（字数 × 4.5–4.8 字/s 估算）。
- 只在"预计时长超过用户所选档位上限"时提醒一句（seedance 2.0 fast 输出 ≤15s、seedance 2.5 ≤30s——**截至 2026-09-14；以 `references/platforms.md`「模型与限额」表为准**），**不替用户改档**。
- 模板 B（多段分镜）与 C1b（两段式）仍为备选，仅在所选模型装不下时才用。
- **模板按分类取用**：先定分类，再取对应模板骨架；下方模板是骨架与示例，不是填空卷。

## 0.1 画幅：默认 9:16 竖版（rules 第26条）

> **画幅由用户在平台自行选择，提示词里的画幅句改变不了成片画幅**。本节的落点=①**交付时提醒用户"比例手选 9:16"**（写进四项核对）；②横版素材要出竖版时，用它描述取景/处理方式（下两路）。

横版源片（16:9/4:3 的参考视频、原片）改竖版有两条路，**两条都必须在提示词里写清竖版怎么来**（不写就等于交给模型随手裁）：

- **路① 提示词描述取景**：人物为中心取竖条、人物在画面水平中央、完整入画、高度约占画面高 70%、不拉伸压扁、被裁掉的背景不新造场景、镜头全程静止。
- **路② 本地预转竖版再上传**（最稳）：先用工具转，输入输出画幅一致，模型不再重构图。

```
python tools\竖版画布.py -i "<横版源片>"                 # 默认 crop：满屏竖版，只裁左右、高度全保留
python tools\竖版画布.py -i "<横版源片>" --mode pad       # pad：不裁切的竖版画布（上下模糊填充）
```

走路②时提示词里补几何句：`画面内容完整保留，不裁切、不放大，镜头不推近不拉远；人物在画面中的大小与位置自始至终不变`。选哪种见 rules 第26条（本机 L9 有更细的取景写法，优先；替换类驱动片按 L10 不转竖版）。

## 模板 A：图生视频·单段（口播/展示 ≤ 模型单次上限，一次生成）

默认模型 seedance 2.0 fast 上限 15s；seedance 2.5 上限 30s（**截至 2026-09-14；以 `references/platforms.md`「模型与限额」表为准**）。用哪个模型以用户/审批为准。

### 骨架

```
（完全参考图片1的人物形象：{人物造型句}，{场景句}，{机位句}，9:16竖屏，无任何文字/字幕，全程绝对无运镜。
口播与{台词音频}完全同步——{动作+台词小节}……按台词顺序逐一对应。
画面光线明亮均匀，{状态描述}，无AI畸变。）
```

**约束**：生成类只引用**真实上传的素材**（图片1/音频1）；禁止出现"参考视频/视频1"字样（见 rules.md 第10条，已验证会整条作废）。

### 完整示例（示例-大礼盒促销·网页可用版）

```
（完全参考图片1的人物形象：短黑发戴眼镜女老师、浅灰色衬衫、红底促销直播背景板+黑色桌面，固定中景正对镜头，9:16竖屏，无任何文字/字幕，全程绝对无运镜。
口播与音频1完全同步——双手拿起与图片1完全一致的橙色“课程礼盒”，轻轻晃一晃，略带调侃地说"已经买了我这套四六级课程的对不住了"；放下盒子，双手合十上下摇晃，语气加重"昨天买的对不住了"；用指尖轻轻敲一下桌面，压低声音"前天买的更对不住了"。
画面光线明亮均匀，自然松弛的直播口播状态，无AI畸变。）
```

反面样例（已验证作废）：开头写"完全参考视频1：……"但**没有传任何参考视频** → 口型台词全对不上、动作不流畅。

反面样例（原版提示词的问题）：台词与动作混排、负面词只有句尾一条、没有人物锚定句——导致「好的抽卡被放弃」。

## 模板 B：图生视频·多段分镜（仅备选：生产条件受限且无法用 2.5 单段时）

> 台词 >15s 默认直接 2.5 单段（见第0节），**不默认拆分多段**；本模板保留为受限备选。

### 骨架

每段 = 一个完整镜头单元，段内同模板 A；段间只写承接点（人物形象/背景环境/人物位置/持盒状态），承接句逐字复用第一段。负面词每段重复。每段标注预计时长。

```
【第1段·预计 Ns】
（{完整锚定句，同模板A}。口播与音频X完全同步——{动作+台词小节1..k}。……）

【第2段·预计 Ns】
（完全承接上一段的人物形象、背景环境、人物位置和持盒状态：{同一句人物+场景复用}，{机位句复用}。口播与音频X完全同步——{动作+台词小节}。与前一段完全同光线同色调同人物，无缝衔接，无AI畸变。）

【第3段·预计 Ns】
（同第2段结构……）
```

### 切段原则

1. 语气拐点处切（吐槽→揭晓→卖点）
2. 每单元 8–20s，不切在句中间
3. 单元是独立镜头，通过剪辑跳切衔接

### 完整示例（三段式，即梦 agent 风格 + 时长标注补全；此示例需真实上传"视频1"参考视频，仅用于多段生成类且有视频输入的场景；无视频输入时把"参考视频1"全部替换为"参考图片1"）

```
【第1段】预计 0–13s
（完全参考视频1：短黑发戴眼镜女老师、浅灰色衬衫、红底促销直播背景板+黑色桌面，固定中景正对镜头，9:16竖屏，无任何文字/字幕，全程绝对无运镜。口播与音频1完全同步——边摊手边轻轻摇头吐槽"便宜的时候你不买，七折的时候你还不买"；身体微微前倾接"这下好了，终于被你等到了"；双手拿起与图片1完全一致的橙色“课程礼盒”举到镜头正前方完整展示，对着镜头伸出五根手指强调"我的四六级课程，限时五折"。画面光线明亮均匀，自然松弛的直播口播状态，无AI畸变。）
【第2段】预计 13–26s
（完全承接上一个片段的人物形象、背景环境、人物位置和持盒状态：同一短黑发戴眼镜女老师，穿浅灰色衬衫，固定中景正对镜头，9:16竖屏，无任何文字/字幕，全程绝对无运镜。口播与音频1完全同步——双手扶着橙色“课程礼盒”，用手指点向观众方向亲切讲解"12月份备考四六级的小同学们，抓紧囤上它"；轻轻把包装盒转半圈展示正面和侧面"单词解题技巧真题模拟预测，你要的全在这个里面了"；轻轻摇一下头，摊开两只手"不用东拼西凑，不用再花钱买别的了"。与上一段完全同光线同色调同人物，无缝衔接，无AI畸变。）
【第3段】预计 26–40s
（完全承接上一个片段的人物形象、背景环境和人物位置：同一短黑发戴眼镜女老师，穿浅灰色衬衫，固定中景正对镜头，9:16竖屏，无任何文字/字幕，全程绝对无运镜。口播与音频1完全同步——把包装盒放回桌面，伸出第1根手指数第一个赠品"而且现在下单还送配套视频精讲"，伸出第2根手指"和艾宾浩斯打卡本"，伸出第3根手指"以及急救班"；拍一下自己胸口"基础差跟着我好好学"，比出数字1的手势"每天一小时"，最后握拳向上加油"考试惊艳所有人"。与上两段完全同光线同色调同人物，无缝衔接，无AI畸变。）
```
> 本示例已按 **rules 第39条（笑容闸门）** 去掉"笑着/眼睛亮起来"这类表情词：叙事型带货默认不写笑，动作细节照写；只有文案偏调侃的段落才给一次轻微笑意。

## 模板 C：参考视频生视频 / 参考视频替换（复刻原片、替换主体）

四种变体：C1 全片替换 / C1b 两段式（备选）/ C2 局部替换 / C2b 图片驱动双替换。

### C1 全片替换（主体换成自己的角色）

**骨架：主体锚定 + 原片节奏 + 台词插入点 + 音色锚定**（先识别素材：单主体则删掉"其余演员"句；背景色抽帧确认后写"从`实际背景色`切换"；硬质产品换软体角色必须加"材质"行；无台词片删台词/音色行、加"音乐沿用原声"行）

```
（主体：@{主体图}的角色完整复刻@{原片}中主体的动作与行为，[仅多主体时：其余演员和场景保持原样]，不做任何变动。
材质：[硬质产品替换软体/弹性角色时必写] 主体像原片角色一样Q弹软体化——跳舞时发生拉伸、弯曲、扭动的弹性形变，摆动跟上节拍，姿态活泼，绝不能像刚体一样僵硬平移。
节奏：参考@{原片}节奏，以视频画面变化为核心，完整复刻整段动作编排（跳舞、转身、挥手、节奏卡点一一对应）。
台词："{台词1}"（{动作/表情注}）…（保持到指定节点）
形象：{造型描述}，脸部模型始终和@{脸模图}保持一致。
音色：参考@{音色参考}，语速{快/慢}，在{秒数}内说完。
音乐：背景音乐完全沿用@{原片}的原片原声，不要重新配乐、不要添加任何新的音效。
画幅与负面：9:16竖屏（默认；横版源片先用 `tools\竖版画布.py` 转竖版再当@原片上传，见 rules 第26条），画面内容完整保留、不裁切不放大、不推近拉远；不要有任何字幕生成，不要带任何运镜效果。
审查：不要有任何文字和主体脸上的黑色块。）
```

要点：**有原片才用@引用**；原片节奏是"核心"（口径：「以视频画面变化为核心要求，只替换视频中出现的主体」「严格参考节奏」）；BGM 是否保留要单独声明（空降样本：不加 BGM）。

### C1 成功实战模板（2026-09-08 考研真题拟人化替换，2/2 成功；可直接改商品名复用）

结构=五个分节+一段约束，全部引用同一个 @视频1（原片）：

```
（主体：{商品封面图}拟人化替换@视频1完美成品视频中的唯一主角，赋予新主体像@视频1主角一样的Q弹软体生命感——跳舞时主体发生拉伸、弯曲、扭动的弹性形变，摆动跟得上音乐节拍，姿态活泼生动，绝不能像硬纸板一样僵硬平移；完整复刻@视频1主角的整段动作编排——跳舞、转身、挥手、节奏卡点一一对应，动作风格与@视频1完全一致。
音乐：背景音乐完全沿用@视频1的原片原声，不要重新配乐、不要添加任何新的音效。
背景：背景保持@视频1的原构图与流动节奏，仅色彩由原片浅紫蓝整体切换为新主体封面主色（亮橙色系）的星空，与橙色商品封面呼应。
镜头：与@视频1保持完全一致，9:16竖屏（横版原片先用 `tools\竖版画布.py` 转成竖版再当@视频1，见 rules 第26条）。
约束：不要有任何字幕生成，不要出现任何文字，不要添加原片之外的新运镜，主体无AI畸变、无破损、无变形。）
```

**链式参考**：同系列第二单把上一单成功成片作为新@视频1+换新商品封面图（实测成功；成功成片风格已稳定）。产线化：第一单=原片起步，后续单=上一单成功成片+新商品图。

### C1b 长视频两段式（仅备选：2.5 不可用时的拼接方案；默认 >15s→2.5 单段）

- **每段输入**：@视频1（参考视频裁 8–11s，带原声）+@音频1（音色采样 3–5s，**内容与台词无关**，只取声线）→ 总计 ≤15s（2.5 版则视频 ≤15s+音频 ≤15s，整段一次出）。
- **每段提示词**：C1 主体句（完全参考@视频1）+ 台词引号（按句切该段内容）+ 动作单元（对应拆分，逐句前置）+ 音色行（"音色完全参考@音频1（参考人物的说话声）"）+ 负面词写死（无字幕/无运镜/无AI畸变）+ 标注预计时长。
- **段间**：段1 结尾姿态句=段2 开头承接句（逐字复用，如"双手摊开、红杯已在桌面、正对镜头、位置不变，无缝衔接"）；台词切点=语气拐点（揭晓/赌注之间），不在句中间切。
- **拼接**：同参数生成→剪映首尾跳切→接缝跳变前后各掐 0.2s→响度统一。
- **fast 版必做**：台词过耳核一遍（rules 第15条）；手部穿模/多指抽帧检查。
- 上下限数字：**截至 2026-09-14；以 `references/platforms.md`「模型与限额」表为准**。

完整成功示例见样本库样本4（四六级报名两本书 v7/v6，源码在 `${SAMPLES_ROOT}\四六级报名两本书\文案\提示词.txt`）。

### C2 物件/局部替换

```
（角色@a完整复刻@b中主体的动作，其余演员场景不变；@b做{动作}时把{物件}替换为@c的{物件}，此时主体仍是@a；{变身时刻}直接变成@c的形象，服饰切换为@c设计，脸部模型始终与@d一致。说出台词："……"。生成视频不要有任何文字和主体脸上的黑色块。音效用@b的原音效，BGM不附加。）
```

**风险**：影视原片替换大概率卡版权审核；审核规避处理过审但效果打折——生成前把过审策略和代价讲给用户听，让他决策。

### C2b 图片驱动双替换（无参考视频，生成类；样本7 形态）

**适用**：只有图片素材、无任何参考视频，但需要"主体动作/场景"+"人物形象"+"手中物件"三者分离替换（例：沙发坐姿拿书图做主体+站姿图做人物形象+三本书封面图替换手中书）。

```
（完全参考@图片A的姿势与场景：{坐姿/场景句按@图片A原样}；人物形象替换为@图片B的主体——{造型句}，脸部模型与@图片B完全一致；
{手中/身上物件}全部替换为@图片C……（多物件按@图片C/D/E 逐一列明、封面细节精确呈现、全程只出现替换后物件）——注意：不得出现@图片B 的背景道具（招牌/价签/摆件），背景一律沿用@图片A；
固定中景正对镜头，光线明亮均匀，与@图片A完全同画质同色调，9:16竖屏，不要有任何字幕、任何叠加文字，全程绝对无运镜，无AI畸变，不要有任何文字和主体脸上的黑色块。
台词用以下内容朗读，口型与台词对应，动作语气一一对应，动作连贯自然、手势自然不浮夸，面部表情自然、只随语气有极轻微变化，手部动作始终在画面内：{动作+台词对应小节}……音色完全参考@音频1（参考人物的说话声），语速偏快、情绪饱满，整段台词在约N秒内说完。）
```

要点：
- 三张图角色分别写死（主体图=动作场景、形象图=脸+造型、物件图=替换内容），正反各一句排除（"背景沿用A、不出现B的背景道具"）——防模型混用两张图场景。
- **人物形象句放最前 + 服装对比式排除**（rules 第20条）："服装由@图片A的深色印花长裙替换为@图片B的黑色圆领上衣+麦克风，与@图片B一模一样，不得出现@图片A的服装"——光写"人物形象替换"只换脸不换衣。
- **人物形象图必须先"去杂"再上传**（rules 第20条）：裁到人物半身，横幅标语/海报/照片/价签区域重度模糊；提示词再加"不得出现@图片B背景的任何文字、标语和Logo"——否则模型会把标语直接搬成片头叠加水印（实证）。
- **物件替换=唯一来源+排除主体图旧物件**（rules 第20条）："封面与@图片C/D/E一模一样，不得修改臆造混杂；不得沿用@图片A中的旧书；三本同时可见、顺序照姿态图；整个视频只出现这三件"。主体图自带物件时，优先把旧物件区域从主体图上裁掉/遮盖再上传。
- **台词固定句**：台词引号前加"引号内为唯一台词，朗读必须一字不差，不得改词、不得漏句、不得添加"（多图长提示词模型易自读改词/漏句）。
- **一次多卡**：双替换类选中率低，同一提示词抽 2–3 张卡逐张筛（无字幕/形象对/服装对/物件对/台词逐字），不做单卡评审。
- 生成类禁令（rules 第10条）：全篇只引用真实上传的 @图片/音频，禁止写"参考视频/视频1"。
- 长度判断与模型选择同第0节。

### 替换类独有的判断信号

- 素材里有参考视频（原片）或文件名含"原片/参考/神临/天降"这类
- 提示词出现「复刻@xxx」「和@xxx保持一致」「只替换主体」「其余保持原样」
- 目标不只是"像"，而是"同一段动作换个人/换件衣服"

## 模板 D：音乐二创 / 翻唱类（rules 33–36，待验证）

**适用**：把有剧情/台词的原片二创成"换世界观 + 唱起来"的形态（例：华强买瓜→迪士尼王子公主音乐剧）。
**工作顺序 = 声音先行**：先出歌 → 按原片镜头切 1–2 句短段 → 每段一张关键帧 → 逐段配口型 → 接回时间线。
拆解流程与报告模板见 `references/playbooks.md` 第二部分。

### D1 作曲 / 演唱指令（给音乐生成模型；中文原词一字不改）

```
用下面这段中文台词直接作曲并演唱（不翻译、不改词、不改顺序）：
{按角色与顺序排列的台词原文，逐句分行}
风格：{如"迪士尼王子公主音乐剧感"}；{男声/女声/对唱}分角色演唱，戏剧感强；
要求：旋律贴合声调，不要倒字变调；情绪冲突按台词原顺序往上走；
时长约 {N} 秒。
```

### D2 关键帧图（每段一张；图片编辑/生成）

```
以@图片1（原片关键帧）为准：人物站位、镜头角度、背景环境、画面构图全部保留；
只把人物造型换成：{服装/发型/妆造/表演状态，统一往 {风格} 靠}；
不要改变背景，不要改变镜头角度，不要新增人物或道具；画面里不要出现任何文字。
```

### D3 逐段口型 / 表演（视频模型；每段 = 一张图 + 一段音频）

```
以@图片1为唯一画面来源，人物与@图片1完全一致，只允许自然演唱口型与轻微表情变化；
口型与@音频1逐字同步；固定机位，全程绝对无运镜；9:16竖屏；
不要有任何字幕；不要出现任何文字（不要生成水印，不要生成Logo）；无AI畸变。
```

### 要点

- **切段 = 原片镜头切点**，一句或两句一段（rules 34）；段短 → 口型更稳、单段砸了可单独重做。
- **歌词/台词一字不改**，模型只负责作曲与分角色演唱（rules 35）；不要写新剧情。
- 动手前先列**保留/替换清单**（rules 36）：站位、镜头、背景、台词原句=保留；服装、发型、妆造、表演状态、曲风=替换。
- 装配：逐段生成口型 → 接回时间线 → **字幕在后期加**（不写进生成提示词）。
- 光影不统一时走「全景空镜 + 局部重绘」（rules 37，待验证）。

## 模板 E：分段多提示词骨架（长视频 / 多主体替换）

**什么时候用**：一条片子**超过平台单次生成时长**，或**每段都要做多主体替换**——**不要**为凑"单主体"把片子切成 2–3 秒的碎块（会把素材与逻辑切乱），而是：

**切法三条**：
1. **按"大场景变化的转场"切**（背景/机位整体切换处）——不是等长、也不按主体在场隔离；切完每段自然落在平台单次生成的时长内（实例：9.0/9.15/2.9/10.05s）。大场景转场用**粗窗聚类**找（0.5–1s 窗签名 + KMeans，工具里对应 `成片拆解.py --scene`），细粒度硬切点用 `tools\成片拆解.py`（用于段内校对）；
2. **段短于模型最短输出（4s）**：按最短值生成、后期掐短，或与相邻段合并重切；
3. **缺量补料**：某段明显偏短时，补一段**同角色**的镜头凑够（补料段的主体要单独标注，见骨架里的【分段提示】）。

**素材口径**：**每段挂全套角色素材**（视频 + 站位图 + 该段出现的每个主体的角色图）——分段不代表把主体拆开；实测（红白模四段）每段都是红+白同场。

**骨架（一个项目一组提示词，逐段一块）**：

```
【段1】{时长}（源区间 {a}–{b}s）——素材：视频1_段1 + 站位图 + 图片1~N
【本段要替换的主体】{红：1 个→@图片1；白：M 个→@图片2~@图片N}。注意：{开头 X 秒只有红色人形 ……}
【站位与角色】{红→@图片1 的锚定句；白→@图片2~N 按站位图从左到右一一对应；同一人穿不同服装时写明"脸型发型一致、只有服装不同"}
【分段提示】{该段特有的时间/主体变化，例：8.5 秒之后只有红色人形，不要凭空生成白色人形}
【排除】同一角色不得重复出现两遍；不要出现第三类人；不要新增人物。
【表情与动作必须跟着原片】…（原片直投替换骨架的四段，见 playbooks.md 第一部分）
【锁定】镜头/构图/位置/节奏/背景/光影不变；无文字水印；静音；时长一致。

【段2】…（同样结构；只改【本段主体】【分段提示】与素材名）

【段3】…
```

**要点**：
- **每段的【本段主体】与【分段提示】都要改**——这是分段版最容易漏的地方（段内主体与素材必须一一对应）；
- 段时长低于模型最短输出（4s）时：**按最短值生成、后期掐短**，或与相邻段合并重切；
- 生成顺序：**最短/最简单的段先跑**，多主体段最后跑；
- 拼接前先按"段序"核对每段的**实际时长**，接缝处前后各掐 0.2s。

## 模板 F：文生视频（纯文字，无任何素材）

> ⚠️ **未验证：本机暂无文生视频样本**。以下骨架按"无锚定 → 全部靠文字描述"的原理推写，第一条真实需求进来后补样本并转正。

**适用**：用户什么素材都不给，只给一段文字（或一句需求），要一条视频。**不引用任何 @图片/@视频/@音频**（引用一致性：没上传的不能写，rules 第10条）。

**为什么难**：没有图片锚定，人物长相、场景、风格全靠文字，**跨段一致性只能靠描述词逐字复用**（rules 第2条的做法在这里从"辅助"变成"唯一手段"）。

### 骨架（六节；分节名可合并，内容不可省）

```
【风格】{一句话定体裁与质感}，{画幅}，{时长}。
【人物】{性别+年龄段+发型发色+脸型/五官特征+服装材质颜色}，{体态与气质}。
【场景】{地点+时间+天气+环境元素}，{光线方向与色调}，{画面纵深与前后景}。
【动作】{逐句/逐段动作：先做什么、再做什么、以什么姿态收尾}，动作连贯、有起点有收势。
【镜头】固定机位/景别（{远景/中景/近景}），全程绝对无运镜，人物在画面中的大小与位置自始至终不变。
【负面】不要有任何字幕，不要出现任何文字（不要生成水印，不要生成Logo），无AI畸变，不要新增未描述的人物或道具。
```

**写法要点（四条）**：

1. **描述词逐字复用**：多段/多镜头时，人物句与场景句必须**逐字复用**，任何措辞变化都会让人物漂移（rules 第2条）。
2. **抽象词翻译成画面**：模型渲染不了"很有氛围""高级感"——要落成**物、动作、光**（"暖黄台灯光从右侧打来，桌面有一杯冒热气的水"）。
3. **一镜一动作**：单段只写一个连续动作，不要在一段里塞多个场景切换（要切换就分段，见模板 B）。
4. **负面词每段写死**（rules 第1条）：不要有任何字幕 / 全程绝对无运镜 / 无AI畸变；文生视频尤其容易"自己长文字"，结尾再单独成句 `不要生成水印，不要生成Logo。`（rules 第29条）。

### 完整示例（**未验证，仅示范格式**）

```
【风格】写实纪录片质感，9:16竖屏，约10秒。
【人物】一名三十岁上下的男性教师，短黑发、戴细框眼镜，穿浅灰色棉质衬衫，体态清瘦、站姿放松。
【场景】晚间的书房，木色书桌、台灯与一摞书，窗外深蓝色夜空；暖黄灯光从画面右侧打来。
【动作】他先低头翻一页书，随后抬头望向镜头，手指轻点书面，最后双手合拢放到桌面上收势。
【镜头】固定中景，全程绝对无运镜，人物在画面中的大小与位置自始至终不变。
【负面】不要有任何字幕，不要出现任何文字，无AI畸变，不要新增未描述的人物或道具。
不要生成水印，不要生成Logo。
```
