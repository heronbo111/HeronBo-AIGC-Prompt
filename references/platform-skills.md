## A. 15 秒竖版 UGC 五段式（官方「穿搭上身试穿视频生成」）

**默认参数**：15 秒 / **9:16** / 720P / `seedance2.0_vip`。（与规则26「默认竖版」一致，可作为佐证。）

**提示词结构**：`整体风格声明 → 分时段动作描述 → 全局风格调性 → 参考素材标记`

**固定分段**（15 秒五段，可直接借用到口播/展示类）：

| 时段 | 内容 |
|---|---|
| 0–3s | 展示起手状态（如手持待穿服装面向镜头） |
| 3–5s | 第一件事（穿上衣）＋整理＋展示效果 |
| 5–8s | 第二件事（下装/外套）＋整理＋展示版型 |
| 8–11s | 补齐配件/鞋，后退展示整体 |
| 11–15s | 定格最终造型，微笑收尾 |

**原生感要素**（区别于棚拍）：手机手持拍摄、轻微抖动、自然光线、无明显滤镜、真实博主感；禁止过度精致棚拍。
**细节要求**：必须写清版型、材质、颜色。
**自检清单**（7 条，可作投稿前模板）：范围核对 / 素材齐备且可用 / 按分时段框架生成且含完整动作 / 默认参数正确应用 / 末尾引用标记正确 / 已交用户确认才提交 / 不含违规内容。
**资源引用语法**：平台技能里用 `<<<avatar:模特资源ID>>> <<<product:服装资源ID>>>`（接口侧写法；网页端仍用 `@图片N`）。

## B. 电商爆款结构（@Carson「爆款电商短视频题材创意」）

**时长与节奏**：优选 **8–15 秒**，最长不超 25 秒；**每 2–3 秒切一次镜头**，拒绝长镜头/静止空镜/缓慢推拉；全程只讲 1 个核心卖点（最多 2 个）；**3s / 7s / 12s 三个位置必须放画面冲突或字幕亮点**防划走。

**爆款万能结构（必套用）**：

```
0–3s   强钩子（视觉/痛点/悬念）
3–10s  痛点场景 ＋ 产品实操演示
10–15s 效果对比 ＋ 信任背书 ＋ 价格福利
结尾    行动引导（CTA）＋ 利益重复
```

**五个钩子方向**：痛点暴击 / 视觉强反差（前后分屏、脏→干净）/ 悬念好奇（内幕、避坑、90%人踩坑）/ 利益前置（低价、限时、补贴、源头价）/ 反常识颠覆。
**结尾要求**：字幕＋口播双重 CTA；重复核心利益；**拒绝黑屏戛然而止**，定格产品＋价格 2 秒。
**避坑（直接拉低完播）**：开头慢铺垫/空镜/自我介绍；一次堆 5 个以上卖点或讲参数；长镜头、画面杂乱、字幕过小；BGM 嘈杂、语速平缓、书面文案；素材与产品场景不匹配。
**平台级全局约束（与我们实测一致）**：**有参考图时必须调用 multimodal2video 全能参考，不能使用首帧**。

> ⚠️ 与我们的差异：该技能强推**大字幕**（"静音用户也能看懂"）。本 skill 交付**默认无字幕**（规则1/20）——字幕属**投放侧后期动作**，不要在生成提示词里要求画面出文字。

## C. 微表情时间轴（官方「AI演员微表情导演」）——最值得吸收

**情绪拆解公式**：`动机 + 眼神 + 呼吸 + 脸部 + 身体 + 声音 + 收尾 = 一个完整情绪`。

**同一句台词给 3–6 版不同层次方案**（示例：一句"滚"）——笑骂 / 委屈 / 失望 / 愤怒 / 崩溃 / 心如死灰，每版用"眼神→嘴/呼吸→身体→声音"的链路写。可直接搬到我们的口播多方案抽卡。

**三条防崩禁忌（原文口径）**：

1. **禁引入环境人物与空间位移**：写"看向父亲""走到桌前"会导致凭空生成多余肢体或强行拉远→崩坏；必须替换为**镜头方向**："看向镜头""视线转向画面右侧""保持半身特写静止"。（对应我们的串人/爆框问题。）
2. **禁抽象心理描写**：模型渲染不了"心里委屈""眼底藏着心思"；必须翻译成**纯物理动作**："眼睑微压""下颌紧绷""呼吸停滞"。
3. **禁动作超载与高频闪烁**：2–3 秒切片内**最多 1–2 个极其微小的局部动作**；必须用"缓缓/极轻微/慢慢"降速词。

**时间轴模板**：以 2–3 秒切片（0-2/2-4/4-6/…/12-15s），**首句必须带角色外貌前缀**，动作连贯、定格收尾，**结尾无黑屏、无转场**。

**影视级情绪基底库（物理动作写法）**：
- 失望/心碎：眼神光亮减弱、眼眶微红不落泪、视线下移、极轻微叹息、嘴唇微张后闭合
- 心虚/撒谎：视线极小范围游移、眨眼频率微增、咽喉微动（吞咽）、呼吸变浅
- 释怀/笑对：眼神由紧绷转柔、一声轻微长呼气、肩膀线条松弛、嘴角极淡微笑
- 愤怒/压抑：眼神定死、呼吸变慢且沉、下颌线极微小紧绷一次、肩膀完全静止死扛

**输出后固定动作**：提示用户上传角色参考图，再批量生成（多张图=多任务并行）。

## D. 分镜 → 生成的注入纪律（@渊静-中意「一图成片」）

- **只把分镜表的"纯镜头内容"注入每次 multi_modal2video 调用**；**删除所有 Markdown 格式字符与分镜表外信息**（表格符号、元信息会污染生成）。
- 结构公式示例：`0-3秒钩子 - 3-7秒动作推进 - 7秒高潮 - 15秒记忆点`。
- **确认"画面扩展边界"**：避免分镜太局限，也避免过度跳脱。
- 若用户要字幕/屏幕文案：分镜表里**只写"字幕建议/屏幕文案建议"，不强制画面生成清晰文字**（与我们"无字幕"一致）。
- 流程纪律：已确认项（类别/结构/方向/边界/时长/比例/分辨率）**不重复询问**。

## E. 角色设定图（@慕影-中意「角色设计」）

- 概念图共 6 种：探索变体 / 定妆立绘 / **三视图 turnaround** / 表情表 / 姿态表 / 比例图；**一律白底或中性底、无环境无场景**（与角色+环境的合成图分开由资产生图/分镜环节做）。
- **翻译原则（实测最大的坑）**：直接拿设计词填 prompt = 标签堆砌，生不出来。出 prompt 前必须做两件事：
  1. **设计→画面翻译**：每个设计决策转成画面上看得见的**物、动作、光**；抽象词不进 prompt，只进它的视觉证据；
  2. **画面构建五件事**（表现图必走）：定妆、构图/景别、光线、底色处理（白底或中性底）、氛围元素（衣摆/光尘/投影/溅水）。
- 群像同框校验：主要角色之间**形状互斥、色彩可区分、剪影不混**。
