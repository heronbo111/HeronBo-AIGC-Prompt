# AI 二创拆解手册（用户发来成片 → 机器证据 → 读片三问 → 拆解报告 → 复现路线）

> 2026-09-12 建立（吸收 B站 `BV1kuKE66Eds`「结果倒推」流程；规则编号见 `rules.md` 第33–37 条）。
> 配套工具：`tools\成片拆解.py`（只出证据，不下结论）。

## 0. 什么时候用

- 用户发来一条 AI 二创 / 爆款成片，说"拆解 / 仿做 / 复现 / 看看这是怎么做的 / 我发你几段 AI 二创，你试着拆"。
- 不适用：用户直接给文案+素材要提示词 → 走 `SKILL.md` 工作流 1（分类）。

## 1. 边界（先说清不做什么）

- **拆解 ≠ 复现授权**：先出拆解报告，再问用户"要不要按哪条路线复现"；**不代提交生成**（规则13 + 工作区铁律）。
- **版权**：影视原片复刻卡版权审核（规则7）；别人的成片只作分析对象，其素材能否直接当驱动片要用户确认。
- **证据分级**：机器证据（本机实测）／视频作者口径（第三方，未经我们实测）分开标注，别把后者写成规律。

## 2. 三步流程

### 第一步 · 机器证据

用户给的是**链接**时先落本地（拆解工具吃本地文件）：

```
python tools\下载B站成片.py "<链接或BV号>" --out "<素材目录>"
```

> 只取匿名可达清晰度（通常 480P，拆解看结构够用）；**下载的成片只作分析对象**，不要再上传去生成（版权，规则7）。

本地文件直接跑：

```
python tools\成片拆解.py -i "<成片>" --asr
```

**有原片可比时**（二创 vs 原片）再多跑一步——省掉肉眼听音判断：

```
python tools\成片对比.py -a "<二创>" -b "<原片>"
```

输出两行结论：**画面**是否同时间轴（序列相关 + 最佳滞后）、**声音**走哪条路线（原声照搬 / 保伴奏换人声 / 整曲重制）。

报告出到源片旁：`<成片>_拆解报告.md` / `.json`。看四类证据：

| 问题 | 报告里看什么 | 判读 |
|---|---|---|
| 节奏跟不跟音乐走？ | 切点与节拍对齐率、平均镜头长 | 对齐率高 + 镜头长 0.5–2.5s → 音乐驱动 → **声音先行** |
| 是不是多短段拼接？ | 镜头数、平均镜头长、段内人脸位移 | 镜头多而短、人物位移小 → 每段一张关键帧 |
| 口型是不是逐段配？ | 转写段边界 vs 切点时间 | 边界与切点同拍 → 音频提前切好；仍需抽帧复核 |
| 有没有声音可用？ | 音轨状态 | `静音轨` → 仅可当无声驱动片；有能量但无词 → 纯音乐/BGM |

> 变化候选点表（算法眼中变化最大的 5 个点）用来对照"硬切/闪黑/大动作"，算法没到阈值的点也在表里，人工复核。

### 第二步 · 读片三问（规则33）→ 定形态

三问结论 + 证据写进报告。形态四选一：

| 形态 | 特征 | 后续走哪 |
|---|---|---|
| 口播驱动 | 有人声台词、镜头长、节奏跟语气 | 规则17 配方（本系列主路） |
| 音乐驱动 | 跟唱口型、切点卡节拍、转写成句成歌 | 本手册第 4 节（规则33–36） |
| 动作驱动 | 舞蹈/运动、无台词或纯 BGM | 规则30/32（深度视频 + 素材分工） |
| 替换驱动 | 画面保留原片、主体被换 | 规则20–24（L1–L4 分级） |

### 第三步 · 出《拆解报告》（模板，可直接复制）

```
【拆解报告】<片名 / 链接>
一、一句话定位：原片/梗 + 新世界观或新风格 + 音乐形态
二、驱动源判定（口播/音乐/动作/替换）：结论 + 证据（切点数、对齐率、转写、人脸位移）
三、时间轴分段表：| 段 | 时间 | 时长 | 台词/歌词 | 镜头与机位 | 变化点 |
四、声音方案：来源（原声/翻唱/TTS）· 切段点 · 风格词 · 是否要「旋律贴合声调」
五、画面方案：保留项 / 替换项 / 关键帧来源 / 生成顺序
六、口型与装配：逐段配口型 → 接回时间线 → 字幕在后期
七、复现路线（本机可用）：给 1–2 条，标成本与风险，等用户决定
八、风险与不确定项：版权 · 付费墙 · 机器判不出、需人工复核的地方
```

## 4. 音乐二创复现配方（照视频四步；待本项目成片验证）

1. **拆声音**：原视频与音频拆开；台词按角色与顺序整理，**中文一句不改**（规则35）。
2. **做歌**：风格词（如"迪士尼王子公主音乐剧感"）+「**旋律贴合声调**」+ 分角色演唱 + 冲突跟着原剧情往上走。
3. **切段做关键帧**：歌出来后按**原片镜头**切 1–2 句一段（规则34）；截原片关键画面，人物站位/镜头角度/背景保留，**只换人物造型**（规则36）。
4. **逐段配口型**：每张图 + 对应音频段生成口型与表演 → 接回时间线 → 补字幕；光影不贴走「全景空镜 + 局部重绘」（规则37，待验证）。

## 5. 常见误判

- 把"参考视频锚定"当万能：锚定会**压制替换指令**（规则20b），拆出"保留即目标"的片子别硬套替换类写法。
- 把静音当"没声音"：静音轨片子照样可以是**无声驱动片**（替换类的干净输入）。
- 只看单帧判形态：形态要看跨段证据（位移/切点/响度），单帧看不出"逐段配口型"。
- 直接拿别人片子的素材开工：版权与授权先问用户（规则7）。

## 6. 案例：四条同源二创的对比结论（2026-09-12，本机实测）

用户提供同一原片的 1 条原片 + 3 条二创（`${AI_CREATE_ROOT}\AI视频素材\参考1–4\`），完整报告见 `参考1-4_二创拆解对比.md`。可复用结论：

1. **三条二创同一套工艺**：歌 / 编舞 / 场景 / 机位 / **剪辑点**（与原片 7.73、11.5、14.9s 三处重合，±0.5s）全保留，**只换人物层**（连群舞的每个人也换）→ 规则36 的原型；支持"按原片镜头逐段重绘"（规则34）。
2. **声音三条路线**（本机 `tools\成片对比.py` 判定）：原声照搬（人声+伴奏 0.99）／保伴奏换人声（伴奏 0.89、人声 0.14）／整曲重制（和声 0.39）——见规则35 的三选一。
3. **时长可超原片**：二创 21–29s，其中两条把结尾舞段延长约 5s → 分段生成时每段允许生成长于原段。
4. **合规痕迹**：一条打「AI制作 纯属虚构」角标、一条走字幕梗化改编——复现时把合规声明留给投放侧。
