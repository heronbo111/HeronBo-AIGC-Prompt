# samples/ —— 规律数据仓库版

> ⚠️ 本仓库为**公开发布版**：`samples/` 里的文案是脱敏示例，真实口播稿/备注只存各机本机样本库（`${SAMPLES_ROOT}`）。
> 各实验的**小文本规律数据**（口播稿 / 提示词 / 六维评价 json / 备注）随仓库走，供参考与复用。
> 大视频（素材 / 成片 / 废片）不进仓库，留各机本地样本库（`${SAMPLES_ROOT}`，见 `references/paths.md`）。

## 目录约定

与本地样本库同构，但只收正文类文件：

```
samples/<实验名>/
├── 文案/口播稿.txt     # 台词原文
├── 文案/提示词.txt     # 生成指令
├── 评价/*.json         # 六维评价（评分工具产出）
└── 备注/备注.txt       # 主观备注 + 生成参数
```

有实验素材 / 成片 / 废片 → 放**本机** `${SAMPLES_ROOT}/<实验名>/` 对应目录，不要进仓库。

## 更新流程（评分后）

1. 本机评分工具打分 → 本地 `${SAMPLES_ROOT}/<实验名>/评价/*.json`
2. 把新 json（连同改动的 文案/备注）拷进仓库 `samples/<实验名>/`
3. `git commit && git push gitee main && git push github main`
4. 其他机器 `git pull`；samples-db.md 的「评价」行由更新者同步刷新

## 注意

- 评价 json 的「成片」字段如实填写成片文件名；评分工具未填时（历史数据为「未指定」）以 samples-db.md 的对应关系为准。
- 废片不进仓库，但**废因**必须沉淀：写进 `备注/备注.txt` 或直接更新 `references/rules.md`。
