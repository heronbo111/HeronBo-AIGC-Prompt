# 给用户：最快用上这套 AI 视频工作台

> 一句话：**普通用户直接下载 v0.4.0 完整安装包，双击即装**——Python、Node、ffmpeg、深度模型和
> 全部依赖都封在里面，离线机器也能用，不需要装 Python/Git。开发者只要规则可 clone 仓库。

## 最快路径（推荐普通用户）

到 GitHub Release 下载完整安装包：

<https://github.com/heronbo111/HeronBo-AIGC-Prompt/releases/tag/v0.4.0>

下载 `HeronBo视频工作台_完整版_Setup_v0.4.0.exe`（约 792MB），双击安装：可选安装位置、
自动建桌面快捷方式；装完从桌面或开始菜单打开「HeronBo 视频工作台」即可。

- Gitee 因附件单文件 **100MB 上限**放不了完整包；Gitee 发行版只有 score-tool 内核，完整包走上面 GitHub 链接。
- 更新工作台：标题条右侧「检查更新」→「下载并重启」（可回滚），不必重装。

## 开发者：只要 skill 规则（不装完整包）

把仓库 clone 到 agent 的技能目录（WorkBuddy 示例）：

```bash
git clone --depth 1 https://gitee.com/HeronBo/HeronBo-AIGC-Prompt.git "%USERPROFILE%\.workbuddy\skills\HeronBo-AIGC-Prompt"
```

- GitHub 更快就用 `https://github.com/heronbo111/HeronBo-AIGC-Prompt.git`
- 没装 Git：下 zip 解压，整个文件夹放进对应 agent 的 skills 目录并命名为 `HeronBo-AIGC-Prompt`
- 别的 agent 目录：ZCode → `~/.zcode/skills/`；Codex → `~/.codex/skills/`；DSH → `~/.dsh/skills/`

做完新开对话说「帮我写提示词」即可触发；技能只产出提示词文字，不代提交、不消耗积分。
要从源码跑图形界面：clone 后 `python tools\部署.py all --yes`（需本机 Python，依赖联网装）。

## 以后怎么收更新

在第 1 步那个目录里：

```bash
git pull --rebase
```

新规则、新模板、新工具都会下来。**没走 git 的（只解压 zip 的）收不到更新**——
那种情况请重新解压一份覆盖，或者找发布人要最新的包。

## 你本地踩出来的规律，怎么回到规则库

这套技能靠「成片反馈 → 沉淀规则」越用越准。你在自己机器上跑出来的新规律写在
`references/rules.local.md`（本机私有、`git pull` 不会冲突）。想让大家都受益：

- 把 `rules.local.md` 里那条整理成「规则 + 依据（日期/来源）」发给发布人，由他并入上游
  `references/rules.md`；或
- 有写权限的话，直接改 `references/rules.md` 后 `git push`（改前先读仓库根 `AGENTS.md`）

## 遇到问题

- **工作台窗口一片空白** = WebView2 运行库坏了：`python tools\部署.py wx --yes` 一条命令修好；
  工作台现在也会自动退到 Edge 窗口，不会白屏晾着
- **想要图形界面但 exe 起不来**：`python tools\工作台.py` 直接跑源码版（要 Python）
- 环境自检：`python tools\环境检查.py`（逐项报缺什么、怎么装）
