# 给用户：最快用上这套 AI 视频工作台

> 一句话：**两步**——把仓库放到 agent 的技能目录，再下那个 18MB 的 exe。
> 不用装 Python，不用下 300MB 的大件；以后 `git pull` 就能收到新规则与新工具。

## 最快路径（推荐）

### 第 1 步：把仓库放进技能目录（10 秒）

Windows 上打开 PowerShell 或 Git Bash，粘这一行（**WorkBuddy 用户**）：

```bash
git clone --depth 1 https://gitee.com/HeronBo/HeronBo-AIGC-Prompt.git "%USERPROFILE%\.workbuddy\skills\HeronBo-AIGC-Prompt"
```

- GitHub 更快就用 `https://github.com/heronbo111/HeronBo-AIGC-Prompt.git`
- **没装 Git？** 把拿到的 zip 解压，整个文件夹放到 `%USERPROFILE%\.workbuddy\skills\` 下，
  重命名成 `HeronBo-AIGC-Prompt` 即可（规则是 Markdown，不需要 Python 也能被 agent 读到）
- 用别的 agent 就换目录：ZCode → `~/.zcode/skills/`；Codex → `~/.codex/skills/`；
  DSH → `~/.dsh/skills/`

做完这一步，**新开一个对话**说「帮我写提示词 / 把这段台词变成生成提示词」，
这个技能就会被触发——它只产出提示词文字，不代提交、不消耗平台积分。

### 第 2 步：要图形工作台就下这个 exe（18 MB，免安装）

<https://github.com/heronbo111/HeronBo-AIGC-Prompt/releases/download/vendor-2026-09-17/score-tool.exe>

双击就能用（自带界面与运行库，不依赖浏览器；WebView2 坏了会自动退 Edge 窗口）。
放到哪都行，建议和技能目录放一起或放桌面。

## 什么时候才需要 `一键安装.cmd`

仓库根目录的 `一键安装.cmd` 是"一遍到底"的安装器：找 Python → 装依赖（优先用仓库自带离线
wheel，免联网）→ 接 agent 通道并**真跑一句验证** → 建桌面快捷方式 → 弹工作台。

**它会顺带拉齐 4 个附件，共约 305 MB**：

| 附件 | 大小 | 干什么用 |
|---|---|---|
| wheels-heavy.zip | 116 MB | numpy / opencv / faster-whisper / onnxruntime（重工具才用） |
| ffmpeg-win64-gpl-shared.zip | 82 MB | 切帧、转码、拆解 |
| depth-model.zip | 88 MB | 深度视频（信息过滤） |
| score-tool.exe | 18 MB | 工作台本体 |

**只有这几种情况才需要它**：要跑「成片拆解 / 成片对比 / 深度视频 / 竖版画布」这些重工具，
或者想要桌面快捷方式、想让 agent 通道自动配好。日常写提示词 + 用工作台，**前两步就够了**。

（需要机器上先有 Python 和 Git。只想更新工作台 exe：`python tools\deploy.py vendor --fetch --exe`，
关掉工作台再跑。）

## 以后怎么收更新

在第 1 步那个目录里：

```bash
git pull --rebase
```

新规则、新模板、新工具都会下来。**没走 git 的（只解压 zip 的）收不到更新**——
那种情况请重新解压一份覆盖，或者找发布人要最新的包。

## 你本地踩出来的规律，怎么回到规则库

这套技能靠「成片反馈 → 沉淀规则」越用越准。你在自己机器上跑出来的新规律写在
`references/rules.local.md`（本机私有、`git pull` 不会冲突）。想让大家都受益：

- 把 `rules.local.md` 里那条整理成「规则 + 依据（日期/来源）」发给发布人，由他并入上游
  `references/rules.md`；或
- 有写权限的话，直接改 `references/rules.md` 后 `git push`（改前先读仓库根 `AGENTS.md`）

## 遇到问题

- **工作台窗口一片空白** = WebView2 运行库坏了：`python tools\部署.py wx --yes` 一条命令修好；
  工作台现在也会自动退到 Edge 窗口，不会白屏晾着
- **想要图形界面但 exe 起不来**：`python tools\工作台.py` 直接跑源码版（要 Python）
- 环境自检：`python tools\环境检查.py`（逐项报缺什么、怎么装）
