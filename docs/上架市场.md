# 把本技能上架到 WorkBuddy 技能市场

> 打包脚本：`python tools\打市场包.py` → 产出 `tools/_stage/HeronBo-AIGC-Prompt-市场版-v<版本>.zip`
> 规范出处：https://open.workbuddy.cn/docs/skill （目录结构与 frontmatter 字段）

## 一、市场没有开放 API，必须人工提交

宿主里的技能市场工具只有 **search / install**，**没有发布接口**——脚本可以打包，但"推上去"这一步
只能在网页完成 + 平台人工审核：

1. 打开 https://open.workbuddy.cn/ ，按提示完成入驻 / 认证 / 开发者信息审核（首次）
2. 点「发布新技能」→ 填下面的元信息 → 上传 zip → 提交
3. 审核：**平台安全审核 → 企业账号还要管理员审核**（1–3 个工作日）
4. 通过后在【技能列表】点「上架」；之后用户在 WorkBuddy 的【专家·技能·连接器 → 技能】里能搜到

（另有腾讯 SkillHub https://skillhub.cn 的「发布团队 skill」入口，流程类似。）

提交后若解析失败，官方给的排查顺序是：目录层级 → frontmatter 字段 → 是否漏文件；
实在定位不了，发邮件给 openworkbuddy@tencent.com，或扫开放平台首页的社群码。

## 三、包内容与取舍（包内 SKILL.md 顶部也写了同样一段）

包结构（照规范，目录最多两级）：

    HeronBo-AIGC-Prompt/
    ├── SKILL.md           # frontmatter 补了 description_zh / description_en / author / category
    ├── references/        # rules / prompt-templates / playbooks / platforms / samples-db / paths / eval-cases
    ├── scripts/           # project_core / score_core / agent_bridge / 评价回收 / 首次配置 /
    │                      # 成片拆解 / 成片对比 / 提示词体检 / 下载B站成片 / 竖版画布 / 环境检查
    └── templates/         # 交付清单模板

**刻意排除**（打市场包.py 的自检会拦住这些东西）：

| 排除 | 为什么 |
|---|---|
| `tools/workbench/`、`workbench_server.py` | 界面本体；放进 `scripts/` 会变成三层，超「最多两级」规范。市场版只出**提示词大脑** |
| `tools/_vendor/`、`tools/dist/` | 离线依赖与 exe，二进制不进市场包 |
| `samples/` 里的大视频 | 体积；且是业务素材 |
| `references/*.local.md`、`*.local.json` | **本机路径/平台取值/账本**，不能外发 |

包内 SKILL.md 与 references 里的 `tools\xxx.py` 路径**没有做批量替换**（怕改错），
而是在 SKILL.md 顶部加了一段**包内路径映射**：`tools\xxx.py` ↔ 本包 `scripts/xxx.py`；
未包含的界面类工具，遇到时跳过该步即可。

## 四、提交前必须过的一关：合规审核（**这是最大的不确定性**）

平台审核含「合规性（是否违反平台规则）」。本技能的核心能力里有
**「保留原片动作构图、把里面的人/物换掉」** 这一类玩法——在公开市场上架，
审核方很可能读作**深度伪造 / AI 换脸方向的内容**而驳回，甚至影响账号。

三条路，风险从低到高：

1. **先只提「净版」**：把 `references/playbooks.md` 的替换类章节和相关 rules 摘掉，
   `description` 也不提「换人」，只留 图生视频 / 文生视频 / 参考运镜 / 拆解。稳，但能力缩水。
2. **先问再提**：邮件问 openworkbuddy@tencent.com（或开放平台社群）「AI 视频提示词生成、
   含参考视频替换类玩法」能不能上，拿到明确答复再提。
3. **直接提全量**：最快，但被驳回要重来，且留一次审核记录。

建议走 2 或 1。**上架 = 内容对外公开**，这本规则库是你自己的方法学沉淀，先想清楚哪些要公开。
