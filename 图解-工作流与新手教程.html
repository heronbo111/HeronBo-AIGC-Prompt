AI 视频提示词生成与拆解

输入「文案 / 台词 + 素材（图片 · 视频 · 音频）」→ 输出可直接粘贴到生成平台的提示词；每次成片反馈都沉淀成规则，越用越准。

① 图生视频 含道具替换 ② 文生视频 纯文字 ③ 参考视频生视频 ④ 参考视频替换生视频 只出提示词，不代提交、不消耗积分 口播只是其中一种形态

第一步永远是"定类型"：按需求走，不按素材走

大类判定信号（用户给什么 / 要什么）模板关键差异
图生视频给图（形象图 / 首帧 / 尾帧 / 四视图），无参考视频；要"让它动起来"A · C2b图片是唯一锚；道具替换（换掉手里那本书）走这条

1整条工作流程

从收到需求到规则更新，一共 7 步。绿色是 agent 干的，蓝色是你干的，橙色是工具。

角色 agent 自动完成 用户 只需回答 / 打分 工具 脚本或窗口
1

落位：先判断是新项目还是沿用工具

新项目 → 建骨架 文案/ 素材/ 成片/ 废片/ 评价/ 备注/（交付时再加 平台上传/），一条命令 python tools\首次配置.py --project "<项目目录>"；沿用 → 不加目录，只追加版本与素材。命名不带日期戳，同主题重开依次加 1、2、3。

2

分类：走哪条路线，取哪套模板agent

看需求（要换人？要复刻动作？只要动起来？）定四大类。注意一件事：分类由需求定，写什么由素材定——不看素材既归不了类，也写不出提示词。

3

素材逐项过一遍，归纳职责agent

每份素材管什么：形象 / 台词 / 音色 / 动作 / 环境。传了视频就逐帧看；提示词里写到的每个 @图片N、@视频N 都必须是真实上传过的。

4

写提示词：模板骨架 + 五条硬项agent

负面词每段写死（不要有任何字幕 / 全程绝对无运镜 / 无AI畸变）· 引用一致 · 动作与台词一一对应且每行标时间区间 · 多段只写承接点 · 每段标预计时长。模型档位由你选，agent 只估时长。

5

交付三件套 + 一句提醒agent

① 提示词正文（代码块，可直接粘贴）② 素材清单（每个文件 + 它的角色）③ 多段时的拼接说明（切点 / 承接点）。并提醒你：比例手选 9:16——提示词里的画幅句不决定成片画幅。

6

交付后自动弹出评分窗口工具

这是硬性动作，不是可选项。窗口版评分工具 tools\score_gui.cmd（优先用打包好的 dist\score-tool.exe）。没保存就关窗会被拦一下。

7

回收反馈，更新规则工具agent

你保存的评分 json → python tools\评价回收.py → agent 按《反馈优化循环》更新 rules.md / 模板 / 样本库，并回报这次改了什么。

2新手教程（第一次用，6 步）

只有第 2、4、5 步需要你动手，其余都是 agent 或工具在做。

第 0 步 · 装好（约 5 分钟）

把仓库克隆到你的 agent 技能目录（ZCode 是 ~\.zcode\skills\，Codex 是 ~\.codex\skills\，DSH 是 ~\.dsh\skills\）：

git clone https://gitee.com/HeronBo/HeronBo-AIGC-Prompt.git

然后跑环境自检：python tools\环境检查.py。缺什么它会打印装法——装之前会先问你，不会静默安装。

第 1 步 · 第一次对话，回答两句话

agent 会固定问两句：

① 「请问您要把项目建在哪里？您提供好素材后，我会自动将其进行归类」
② 「你主要用哪个平台做 AI 视频？即梦 / 小云雀 / updream」

回答完，它建骨架并把路径记进本机配置（references\paths.local.md，不进仓库）。

第 2 步 · 把素材丢进项目文件夹

文案 / 台词、形象图、产品图、音频、要复刻的原片——都放进项目文件夹。agent 会自动归类并回报每个文件去了哪（文案/、素材/…）。

不用手动整理；但素材要在对话里给 agent 说清楚，它才能判断每份素材的职责。

第 3 步 · 拿到提示词

agent 给你三样：提示词正文、素材清单、拼接说明。提示词里出现的 @图片1 / @视频1 / @音频1 就是待会儿要上传的那几个文件。

第 4 步 · 去平台生成

① 复制提示词 ② 上传提示词里写到的每个素材（没写进提示词的别传）③ 比例手选 9:16 ④ 选好模型档位再生成。

最常见翻车：画幅没手选、或素材没传全——都会让成片"完全对不上"。

第 5 步 · 成片出来打分

交付时弹出的评分窗口里：选样本 → 选成片 → 六维逐项点分（口型 / 动作 / 形象 / 语速 / 节奏 + 违禁项）→ 五星 + 结论 + 备注 → 保存评分（快捷键 Ctrl+S）。

保存的 json 就是下一轮规则的依据；不保存就关窗会弹窗拦你一下。

第 6 步 · 越用越准

agent 回收这份评分 → 更新规则与模板 → 下一批提示词就更贴合你的实际成片效果。反馈越多，规则越准，这也是这个 skill 与"通用提示词教程"最大的区别。

4为什么它越用越准：反馈闭环

和"通用提示词教程"最大的区别——你的每一次成片评价都会变成下一条规则。

写提示词按模板 + 硬项
→
平台生成你复制粘贴 + 手选 9:16
→
成片可用 / 可改 / 作废
→
评分六维 + 违禁项 + 结论 → json
→
回收评价回收.py
→
更新规则rules / 模板 / 样本库

规则只写「规则 + 依据（日期 / 来源）」：同一现象出现 ≥2 次且因果明确才升为"已验证"，只出现 1 次先记"待验证"。

5速查

模型与限额（唯一真相源：references\platforms.md）

模型运行方式输出上限输入上限备注
seedance 2.0 fast即梦≤15s≤15s（图≤9 / 视频≤3 / 音频≤3）「参考视频≥12s」与「整条台词配音≥12s」互斥
seedance 2.5即梦≤30s≤30s（视频≤15s + 音频≤15s）支持 4K；成本高，按成本策略选
MiniMax H3开源 · 本地 / 云分片推理 60s+参考视频建议 ≤10s支持首尾帧与全能参考；3D 类用三视图固定角色

模型或限额有变动时只改这张表，rules 与模板只引用、不写死数字。

写提示词的五条硬项（一条都不能省）

① 负面词每段写死：不要有任何字幕 / 全程绝对无运镜 / 无AI畸变
② 引用一致：出现的 @图片N/@视频N/@音频N 必须真实上传过
③ 动作-台词一一对应：动作前置、台词加引号、一行一组、每行标时间区间（连续不跳变）
④ 多段只写承接点：形象 / 背景 / 位置 / 持物；描述句逐字复用第一段
⑤ 每段标预计时长（只估算，模型档位由你选）

替换类动作戏：六步流水线（playbooks.md 1.2）

备三视图 → 先去水印（不去会被模型学进画面）→ 拆镜 + 单人物化（双人同框会被合成一个人）→ 过渡帧划归对应角色段（防漏换）→ 逐段替换（2.0 / 2.0 fast 够用）→ 按原序接回并记录每段衔接方式。
